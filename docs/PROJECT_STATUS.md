| 두 카메라 판정 | 제한적 구현 | 동일인 수동 확인·수신 시각 조건·양쪽 라벨 일치. 가림 보완 결합 아님 |

| 기록 검토 | 구현 | 목록·무결성·프레임·시간축·원본 저장 영상 대조 |

## 검증 상태

- 개발 환경에서 생성 영상·SDK 대역·오류/변조·기록 재계산·브라우저 동작을 검사했습니다.
- 최신 기능 커밋 [a5ee480](https://github.com/zntks1234/bed-pose-skeleton-ai/commit/a5ee4803eae61bb9cdc807c98e47ef60ced32266)의 [GitHub Actions](https://github.com/zntks1234/bed-pose-skeleton-ai/actions/runs/40798135896)는 Windows/Linux 테스트·빌드와 Linux 브라우저 검사를 통과했습니다.
- 사용자 Windows PC의 실제 모델 실행과 일부 프레임 육안 검토 보고가 있습니다. 통제된 실제 장치 성능 시험과 구분합니다.
- 실제 사람의 관절 정확도·자세별 Precision/Recall/F1·보류율·전환 지연·다중 카메라 종단 지연은 아직 검증되지 않았습니다.
- 문헌 37편 중 P11·P12·P19·P34는 본문 미확인입니다. P35의 2022 ACM 최종판도 본문 미확인이고, 확인된 공개 판본의 근거만 사용합니다. [문헌 확인 범위](research/LITERATURE_REVIEW.md).

테스트 수는 변경되므로 이 문서에서 매번 누적하지 않습니다. 특정 실행의 결과는 해당 커밋의 Actions를 확인합니다. 기록 검사 통과를 자세 정확도나 실제 노출 프레임의 완전 수신으로 해석하지 않습니다.

## 다음 단계

실제 침대 영상에서 현재 구현을 평가합니다. 우선 한 명·한 카메라·이불 없는 조건에서 세 자세 유지와 전환, 서 있음 같은 범위 밖 동작을 확인합니다. 목표 지시와 별도로 실제 수행 자세를 검토하고 오분류·보류·관절 오류를 기록합니다. 이후 시점·가림·주변 인물·두 카메라 조건으로 넓힙니다. 순서와 완료 기준은 [로드맵](../ROADMAP.md)에서 관리합니다.
