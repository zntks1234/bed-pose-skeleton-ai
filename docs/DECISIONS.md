## Windows 경로 검사 수정 · 2026-10-29

최신 Actions의 Windows 작업은 242개 중 경로 표현 비교 2개가 실패했습니다. 임시 경로의 `RUNNER~1`과 정규화된 `runneradmin`을 문자열 그대로 비교한 것이 원인이었습니다. 비교 보고서의 누락 경로, 설정 상대 출력 경로와 영상 경로의 예상값을 `Path.resolve()`로 정규화하도록 검사를 수정합니다. 누락 기록 보존·다른 작업 디렉터리에서 설정 상대 경로 해석이라는 검증 목적을 유지합니다. 제품 코드·판정 기준은 변경하지 않습니다. Windows/Linux 재실행 결과는 해당 수정 커밋의 Actions에서 확인합니다.

## 브라우저 미리보기 복구 보완 · 2026-10-29

손상된 JPEG의 브라우저 해독 실패를 표시 오류로 처리하고 상태 조회·측정 조작을 유지합니다. 해당 영상·오버레이를 숨긴 뒤 같은 순번도 1초 간격으로 다시 받아 정지 영상에서 복구합니다. 상태 응답보다 새롭거나 같은 순번의 영상 응답은 자체 해독 결과를 사용하여 이전 `preview_error`가 복구 영상을 지우지 않게 했습니다. 단일/격자 화면에 적용하며 실제 연결 실패 처리는 유지합니다.

재현 가능한 Chromium 검사는 `python tests/browser_preview_recovery.py`로 실행합니다(개발용 Playwright와 Chromium 필요). 생성 영상·SDK 대역을 사용하며 이미지 손상, 같은 프레임 재시도, 지연 상태 응답, 단일/격자 표시와 JavaScript 오류를 검사합니다. GitHub Actions의 Linux 작업에도 연결합니다. 자세 규칙·가중치·0.65 기준·기록 형식은 유지합니다.

## 리뷰 후 안정화와 문서·자동 검사 · 2026-10-29

1단계로 미리보기 JPEG 변환 실패를 `preview_error`로 분리했습니다. 분석·진행 중인 기록은 계속하고 실패 프레임의 영상/오버레이는 숨깁니다. 다음 프레임 또는 정지 파일의 화질 전환으로 복구합니다. 2단계로 README의 현재 기능을 진행 현황에 연결하고 과거 설명을 [구현 이력](IMPLEMENTATION_HISTORY.md)으로 옮겼습니다. GitHub Actions는 Python 3.12의 Ubuntu/Windows에서 합성 입력·SDK 대역 테스트와 wheel 빌드를 수행하도록 구성했습니다. 장치·실제 모델·정답 정확도 검증을 대신하지 않습니다. 자동 검사 실행 결과는 Actions에서 별도 확인합니다.

다음 순서는 카메라 해상도/FPS 요청·실제 수신 정보와 성능 표시, 다중 입력 표시 처리 개선, 원본 영상과 기록 프레임 대조, 실제 자료 평가 후 판정/두 시점 보완입니다. 가중치와 0.65 기준은 유지합니다.

## 미리보기 오류와 측정 분리 · 2026-10-28

미리보기 JPEG 변환 실패는 별도의 `preview_error`로 표시하고 입력·추론·진행 중인 기록을 종료하지 않습니다. 실패 프레임의 이전 영상/오버레이를 재사용하지 않으며 자세와 기록 상태는 계속 갱신합니다. 다음 프레임에서 자동 재시도하고 일시정지 파일은 화질 전환으로 같은 프레임을 재인코딩합니다. 실패 화면에서는 침대 영역 편집과 대상 이미지 선택을 막고 측정 종료/재생 조작은 유지합니다. 입력·추론·기록 자체 오류의 기존 종료 정책과 판정 기준은 유지합니다.

## 브라우저 표시 화질 개선 요청 · 2026-10-28

사용자가 브라우저 영상의 현재 화질 설명과 개선을 요청했습니다. 기존 긴 변 1280px/JPEG 85 표시를 표준으로 유지하면서 기본 고화질 1920px/JPEG 95를 추가하고 실제 입력·전달 크기를 표시합니다. 이는 표시 설정이며 카메라 해상도/FPS·모델 입력·가중치·0.65 기준 변경이나 AI 정확도 개선을 의미하지 않습니다. 고화질의 전송/디코딩 부담을 고려해 표준으로 되돌릴 수 있습니다. [세부 기준](PREVIEW_QUALITY.md).

## 기록 시간축 요약 요청 · 2026-10-28

사용자는 판정 기준을 유지하면서 구현할 후속 항목 중 ‘기록 시간축 요약’을 먼저 요청했습니다. 저장 당시의 자세·독립 적합도·보류 사유·실루엣 충돌을 요약하고 원본 프레임으로 이동하는 조회 기능을 추가합니다. 원본 PTS와 수신 시간은 분리하며 프레임 수를 시간 점유율/정답 정확도로 바꾸지 않습니다. 새 자세 판정·가중치 튜닝·보간·전체 실루엣/영상 기록·정답 편집을 추가하기로 합의한 것이 아닙니다. [구현 계약](RECORD_TIMELINE.md).

## 실루엣 오버레이 요청 · 2026-10-28

사용자가 스켈레톤처럼 실루엣을 영상 위에서 확인하도록 요청했습니다. HTML 작업실의 원본 영상 위에 반투명 보라색 인물 영역을 표시하고 관절/실루엣을 각각 전환합니다. 복수 입력에서도 독립 마스크를 표시하며, 동일인 결합 근거나 최종 분류 기준을 추가한 것이 아닙니다. 표시용 축소 PNG는 일시 전달만 하고 기존 희소 관측 기록을 유지합니다. 추정 경계와 잘못된 분할 가능성·미검출을 명시하며 실제 정확도 개선을 합의하거나 확인한 것으로 취급하지 않습니다.

## 인물 실루엣 보조 검사 · 2026-10-28

사용자가 잘못된 가중 근거를 보완할 방법을 논의한 뒤 보조 근거 구현을 요청했습니다. 우선 같은 모델의 인물 분할과 스켈레톤을 대조하고 **일치·충돌·확인 불가를 별도 표시·기록**합니다. 기존 최종 자세·점수·가중치·기준은 바꾸지 않습니다. 추가 모델/학습·얼굴/시계열 분류·ToF/mmWave 융합은 도입하지 않습니다. 검사 초기값과 출처를 프로필에 보존하며, 실제 오판정 탐지 효과나 독립 검증 근거로 확정하지 않습니다. [구현 범위와 검증 한계](SILHOUETTE_SUPPORT.md).

## 판정 기준 유지와 기록 조회 우선 · 2026-10-28

사용자는 현재 실제 영상을 확인하지 않고 진행할 수 있는 기능을 요청하며 판단 기준을 최대한 유지하도록 했고, 제안한 순서 중 기록을 먼저 구현하도록 지시했습니다. 이번 범위는 기존 live 측정의 읽기 전용 목록·검사·저장된 프레임별 결과 조회입니다. 판정 모듈·가중치·0.65 기준과 원본을 변경하지 않으며, 새로운 자세/점수나 실제 정답을 생성하지 않습니다. 기록 요약·화면 내보내기·영상 녹화는 후속으로 둡니다. [구현 범위](RECORD_BROWSER.md).

## 가중 적합도·최소 기준과 점수 차이 처리 · 2026-10-28

사용자는 자세별 가중 근거로 일정 기준 이상일 때 판정하는 방향을 요청했고, 바로 누움·옆누움이 비슷할 수 있어 2위와 큰 차이를 필수로 요구하는 방식에 우려를 제기했습니다. 이에 **최고 점수가 기준 이상이면 1위 선택**, 가까운 2위는 참고 안내, 동점·필수 관측 부족은 보류하도록 0.5를 구현합니다. 점수는 독립 규칙 적합도이며 확률이 아닙니다. 가중치·0.65 최소 기준·0.10 가까움 안내 기준은 버전별 실험 초기값으로 남기고 검증된 성능이나 최적값으로 확정하지 않습니다. [정의·계산·검증 범위](WEIGHTED_POSTURE.md).

## 이전 구현 이력: 새 특징의 최종 판정 적용 요청 · 2026-10-28

사용자가 비교 도구만으로는 요청한 판정 개선이 되지 않았음을 지적하고 실제 분류 적용을 요청했습니다. 이에 규칙 0.4에서 누움 후보의 몸통 기준 2D와 추정 3D를 최종 라벨에 연결합니다. 3D는 보조 단서이며 명확한 2D/3D 충돌은 보류합니다. 기존 서 있음·걸터앉음·침대·시점 조건과 이전 기록의 재계산을 유지합니다. 임계값은 버전별 실험 초기값으로 기록하고 실제 성능·최적 기준·3D 우월성을 확정하지 않습니다. 수동 누움 확인이나 기준 등록을 필수로 추가하지 않습니다. [규칙과 미검증 가정](LYING_ORIENTATION_RULES.md).

## 이전 구현 이력: 학습 전 근거 비교 착수 · 2026-10-28

사용자가 추가 학습 없이 활용할 근거를 더 검토하고 진행하도록 요청했습니다. 기존 자동 규칙, 몸통 기준 2D 특징, 2D+MediaPipe 추정 3D를 동일 프레임에서 비교할 계산·기록·화면·CSV 경로를 구현합니다. **새 분류기 채택이나 3D 우선 적용을 확정한 것은 아닙니다.** 현재 새 항목은 특징만 계산하고 기존 규칙 0.3이 최종 자세를 출력합니다. 수치 기준과 효과는 실제 자세가 별도 확인된 자료에서 검증 후 판단합니다. 분할 마스크·이미지 분류기·학습·침대 기준 높이 보정은 이번 구현 범위에 포함하지 않습니다. [상세 범위](POSTURE_EVIDENCE_COMPARISON.md).

## 자동 규칙 검수 후 구현 상태 · 2026-10-28

사용자가 기존 판정 조건의 검수를 요청해 작업별 관절 충분성의 불일치와 보류 안내를 수정했습니다. 실행 규칙은 0.3이며 기존 0.1·0.2 기록은 당시 규칙으로 검사합니다. 검증 없는 임계값 완화·마지막 자세 유지·이미지 우선 방식·새 학습 모델을 합의하거나 도입한 것은 아닙니다. 실제 품질·시점/반전·전환·두 시점 오분류 검증은 남아 있습니다. [검수 근거](AUTOMATIC_POSTURE_REVIEW.md).

## 관절 부족 보류 조건 수정 · 2026-10-28

사용자 보고의 ‘어깨·골반·무릎·발목 좌표 부족’을 확인하고 하체 누락 시 누움 조건의 몸통으로 비교하는 자동 규칙 0.2를 연결했습니다. 앉음/서 있음 구분과 몸통 정보 부족은 보류하고 기존 0.1 기록은 당시 규칙으로 검사합니다. 최근 최대 300개 처리 프레임의 보류 비율·주요 사유를 입력별로 표시합니다. 실제 촬영 조건의 보류율/정확도 개선은 미검증입니다. [조건과 집계 의미](AUTOMATIC_POSTURE.md).


## 네 점 침대 영역 · 2026-10-28

침대 모서리를 순서대로 네 번 클릭해 지정하고 점 이동·마지막 점 취소·지정 취소를 지원합니다. 볼록 영역 검사, 실제 다각형 내부 여부, 단위 사각형 대응 상대 좌표와 자동 자세 판정/원본·그룹 기록 검사를 연결했습니다. 기존 사각형 기록은 유지하며 네 점을 포함한 통합 입력은 0.3 형식입니다. [사용법과 좌표 의미](BED_REGION.md).


## 기준 등록 없는 자동 판정 · 2026-10-28

사용자가 수동 기준 등록 없이 자동 판단하도록 요청해 실제 카메라/영상의 기본을 실험용 2D 기하 규칙으로 변경했습니다. 침대 영역 지정 후 바로 누움·옆으로 누움·걸터앉음 또는 보류를 출력합니다. 기본 사선·측면 배치와 위 시점 설정의 차이가 있으며 위 시점은 걸터앉음을 판정하지 않습니다. 임계값·정확도는 아직 미검증입니다. 두 시점은 시간/대상 게이트와 양쪽 라벨 일치로 결합합니다. 기준 등록 화면은 기본 흐름에서 제거하고 이전 기록 호환은 유지합니다. [사용법·가정·한계](AUTOMATIC_POSTURE.md).


## 이전 구현 이력: 기준 자세 비교 · 2026-10-28

사용자가 실제 자세 판정을 요청해 카메라별 세 기준 예시를 등록하는 최근접 특징 비교를 연결했습니다. 소수 수동 라벨을 이용하는 지도 방식이며 신경망 가중치 학습은 수행하지 않았습니다. 분류 결과/보류·라벨별 거리·원본 기록 검사와 두 시점의 수신 시각/대상 게이트를 통과한 거리 결합, 종료 후 FIFO 쌍의 통합 예측 기록을 제공합니다. 검증된 범용 분류기·범위 밖 자세 탐지·실제 정확도 확보를 의미하지 않습니다. [사용법과 한계](REFERENCE_POSTURE.md).


## 합의한 방향

1. 카메라 AI와 외부 ToF·mmWave는 독립적으로 분석합니다.
2. 통제된 침대 환경에서 시작하고 실제 사용 환경 확장은 추후 검토합니다.
3. 실시간 분석과 결과 기록을 수행하며 원본 영상 녹화는 선택할 수 있습니다.
4. 시작 시 녹화 여부를 정하고 분석 중에도 녹화를 시작·중지할 수 있습니다. 녹화 여부와 분석은 분리합니다.

다음은 AI가 제안한 설계이며 개별 정책·임계값의 사용자 확정이나 구현·성능 검증 완료를 뜻하지 않습니다.
