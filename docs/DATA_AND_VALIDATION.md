# 데이터 저장·정답 관리·비교 검증 (v0.3)

## 목표

주목적은 **카메라 AI와 ToF·mmWave 센서의 독립 측정 결과 비교**입니다(외부 개발자에게 최종 목적 확인 필요). 정답이 별도로 확보되면 각 시스템의 인식 정확도를 보완적으로 평가합니다.

## 추천 저장 항목 (세부 형식/주기는 미정)

| 데이터 그룹 | 예시 필드/의미 |
|---|---|
| 실험 식별·시각 | 세션 ID, 촬영 시각, 프레임 번호, 측정·처리 시각 구분 |
| 카메라 스켈레톤 | 관절 위치, 모델이 제공하는 인식 신뢰도/가시성 |
| AI 자세 분류 | 라벨, 불확실/판정 불가 여부, 가능한 경우 예측 신뢰도 |
| 상태·이벤트 | 침대 점유, 이탈 시작·완료, 복귀 시작·완료, 자세 변화 |
| 침대 영역 | 영역 좌표, 최초 설정, 자동/수동 수정 시각 및 유효 상태 |
| 계획 측정 | 목표 자세, 단계 ID, 준비·전환·측정 구간 |
| 실제 검증 정답 | 확인 라벨, 이벤트 시점, 검증 상태, 확인 방법/출처 |
| 외부 센서 | 센서 원본 또는 분류 결과, 센서 측정 시각, 라벨 |
| 녹화 정보 | 파일 식별자, 녹화 시작·종료, 세션 연결(영상 자체는 별도 보관) |

모든 처리 프레임 기록과 이벤트 별도 기록은 권장 시작점이나 확정 사항은 아닙니다. 용량, 처리 성능, 개인 정보 보호를 테스트하며 결정합니다.

## 라벨 출처는 반드시 분리

1. **계획 목표:** 실험자가 하기로 한 자세
2. **카메라 AI 예측:** 영상만으로 독립 판단한 값
3. **외부 센서 예측:** ToF·mmWave가 독립 판단한 값
4. **실제 정답:** 관찰자 또는 영상 검토로 확인한 값; 미확인 구간 허용

계획 목표를 검증 정답으로 자동 대체하지 않고, AI 예측을 정답으로 재사용하지 않습니다.

## 두 종류의 평가 (서로 다름)

### A. 시스템 간 일치도 / 2차 교차 검증 (주목적 후보)

- 같은 실험의 동일 시간대와 **공통 분류 기준**으로 정렬해 일치·불일치·판정 불가를 집계
- 유효한 두 결과가 있는 구간의 일치율 및 클래스별 불일치 사례를 보고
- 침대 이탈·복귀 등 이벤트 시점의 차이를 비교
- 판정 불가 구간, 누락 구간, 시간 동기화 오차는 따로 집계
- **두 시스템이 일치해도 두 시스템 모두 틀릴 수 있음**을 명시

### B. 실제 정답 기반 정확도 (보완 평가)

- 실제로 수행한 자세/이벤트가 별도 확인된 구간에 대해서만 정답 기준으로 평가
- 카메라와 센서 각각에 대해 정확도, 자세별 오분류, 이벤트 탐지 결과 확인
- 참가자·세션 단위로 학습/검증/시험을 분리하는 계획을 우선 검토. 같은 녹화의 인접 프레임이나 겹치는 시계열 윈도가 서로 다른 분할에 들어가지 않게 관리
- 참가자 일반화 평가와 동일 참가자의 다른 세션 평가를 구분하고 데이터 수·분할 목록을 기록
- 사전 목표 자세만 있고 수행 확인이 없다면 정확도 검증 완료로 주장하지 않음

## 시간 및 이벤트 비교 주의점

- 카메라 프레임 **촬영 시각**과 AI 결과 **출력 시각**, 센서 측정/전송 시각은 다를 수 있음
- 동시 측정 시간 기준과 허용 오차를 합의하기 전에는 감지 지연을 단정하지 않음
- 자세 전환 중 예측 흔들림을 실제 이벤트로 착각하지 않도록 판단 기준 필요
- 화면에서 사람이 사라짐은 침대 이탈의 충분 조건이 아님
- 침대 영역 보정 중 신뢰할 수 없는 결과를 비교에서 어떻게 다룰지 정해야 함

## 데이터 보안·재현성

- 참여자 동의, 원본 영상 보관 기간, 접근 권한은 실험 전에 결정
- 원본 영상, 개인 식별 정보, 학습/검증 데이터는 GitHub 소스 저장소에 업로드하지 않음
- 모델/프로그램 버전, 촬영 조건, 라벨 수정 이력 등을 기록해 실험 재현성을 확보

## 문헌 조사에 따른 평가 설계 제안

### 추가 기록 항목

- 모델·가중치 식별자/체크섬, 코드 버전, 관절 매핑, 전처리·평활화·분류 임계값 설정.
- 원본 좌표, 신체 기준 정규화 결과, 침대 상대 위치와 침대 영역 버전.
- 검출 박스/추적 ID, 관절별 신뢰도·결측 마스크, 검출/추정 실패 원인, 연속 실패 구간.
- 참가자 비식별 ID, 세션/영상 ID, 촬영 장비·시점·조명·가림 조건과 데이터 분할.
- 원본 촬영 시각 또는 영상 PTS, 수신 시각, 추론 시작/종료·출력 시각. 촬영 시각을 알 수 없으면 대체 시각과 그 한계를 명시.

### 보고할 지표와 해석

| 대상 | 제안 지표 | 함께 남길 조건 |
|---|---|---|
| 관절 추정 | 관절 검출률/누락률, 연속 실패 길이, 정지 구간 흔들림 | 관절별·자세별·가림별 결과; 흔들림은 실제 동작과 구분 |
| 관절 좌표 정확도 | PCK 또는 MPJPE | 수동 관절 정답이 있는 경우만; 차원·단위·정규화·PCK 임계값 |
| 자세 분류 | 클래스별 precision/recall/F1, macro-F1, 혼동행렬 | 라벨 정의, 표본 수, 참가자/세션 분할 |
| 판정 불가 | 유효 판정 비율, 불가/누락 비율과 지속 시간 | 유효 구간만의 성능과 전체 구간 중 적용 범위를 함께 보고 |
| 이탈·복귀 이벤트 | 이벤트 precision/recall, 오경보/시간, 누락 수 | 이벤트 1:1 매칭, 허용 시간창, 중복 경보 처리 규칙 |
| 이벤트 시점 | 기준 시점 대비 시간차·분포 | 시작/완료/예고를 분리; 부호와 기준 시각 정의 |
| 실시간 처리 | 처리량, 프레임 드롭, 전체 지연 분포 | 입력·전송·추론·출력 단계, 장비와 해상도 |
| 센서 교차 비교 | 공통 유효 구간 일치율, 라벨별 불일치, 시점 차이 | 양측 유효 구간 비율, 시계 오차, 정답 평가와의 구분 |

정답 인물 박스를 제공한 관절 모델 평가와 실제 사람 검출기부터 수행한 전체 경로 평가를 구분합니다. 관절 검출률을 관절 좌표 정확도로, 모델 처리 FPS를 촬영 FPS로 대체하지 않습니다. 위 지표의 목표 수치와 허용 오차는 아직 확정하지 않았습니다.

### 공개 데이터의 역할

- **SLP [P01]:** 누운 자세와 가림 조건의 관절 평가/학습 후보. 정적 자세 자료이므로 이탈·복귀의 연속 이벤트 정답을 제공한다고 가정하지 않음.
- **BlanketSet [P14]:** 침대 동작 시나리오 설계 참고. 현재 영상 접근 제한이 있으며 반복 동작의 준동기화는 정확한 관절 정답과 다름.
- **BlanketGen2-Fit3D [P13]:** 가림 증강 연구 후보. 합성 학습 이득과 실제 카메라 전체 경로 성능을 분리.
- **시뮬레이션 위험도 [P25]:** 시뮬레이터가 정의한 낙상 위험 라벨. 실제 이탈/낙상의 관측 정답과 혼용하지 않음.

논문별 데이터 접근·입력 장비·검증 범위는 [참고 논문 상세 문서](LITERATURE_REVIEW.md)에 정리했습니다.
