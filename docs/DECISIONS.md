# 결정 기록 및 미정 사항 (v0.3)

**기준일:** 2026-10-24  
**상태 의미:** 합의 = 설계 목표, 구현 완료가 아님 / 잠정 = 정보 확인 필요 / 보류 = 지금 구현 우선순위 아님.

## 합의한 방향 (유지)

1. 카메라 AI는 외부 ToF·mmWave 센서와 **독립적으로** 자세 및 움직임을 분석
2. 초기에는 **통제된 침대 환경**에 집중, 실제 사용 환경 확장은 선택
3. 실시간 카메라 분석 및 결과 기록, 선택적 원본 영상 녹화
4. 녹화는 시작 시 여부를 묻고 분석 중 시작/중지 가능하며, 분석은 지속
5. 침대 영역은 **최초 자동 인식 후 기본 유지**, 오류 시 자동 재인식 및 사용자 즉시 수동 수정 가능
6. 자세/점유 상태/이벤트를 구분해 분석하고 이탈 발생·유지·복귀 추적
7. 계획 측정에서 단일 자세와 다중 순차 자세 모두 지원
8. 순차 측정은 자동·수동 진행을 모두 지원, 자세별 준비 시간 설정과 준비 완료 입력 둘 다 가능
9. AI 예측, 외부 센서 결과, 목표 계획 자세, 검증된 실제 정답을 구분
10. 필요하면 새로운 자세 분류를 추가할 수 있는 확장성 확보

## 최근 논의로 보강된 방향

- **유력한 주목적:** 카메라 AI와 센서의 결과 일치/불일치 및 이탈·복귀 시점 차이 비교. 실제 정답 기반 정확도 평가는 보완적 검증. **최종 범위 확인 전.**
- **개발 우선순위:** 스켈레톤 실증 → 독립 실시간 측정기 → 외부 센서 비교 → 실험 편의 기능 고도화.
- **유력한 실험 방식:** 참가자가 사전 계획한 자세·동작을 순서대로 수행. 실제 프로토콜 미확정, 자유 측정도 허용.
- **사전 라벨 주의:** 목표로 지정한 자세는 실제로 수행했는지 확인되기 전까지 정답 데이터가 아님.
- 자동 침대 영역 인식이나 순차 측정은 합의된 **최종 목표 기능**으로 유지하되 초기 구현은 단순화할 수 있음.

## 잠정 분류 체계

| 라벨 후보 | 의미 | 미해결 |
|---|---|---|
| 누움 | 바로 누움 | 상세 경계 기준 |
| 옆으로 누움 | 측면 누움 | 좌/우 분리 여부 |
| 걸터앉음 | 침대 가장자리에 앉음 | 침대 위 앉음과 경계 |
| 일어남 | 침대에서 벗어나는 동작 또는 상태 | 이탈 동작과 완료 상태의 구분 |

이 네 항목은 사용자가 알고 있는 외부 센서의 **잠정** 분류로, 외부 개발자 확인 전에는 확정 사양이 아닙니다.

## 미정 (우선 확인)

- 외부 개발자와의 검증 목적 최종 합의, 라벨/이벤트 정의, 센서 출력(원시·분류), 동기화·연동 방식
- 실험 공간 크기와 침대 배치·출입 방향, 카메라 종류/위치/각도/화각, PC 환경
- 스켈레톤 추정 후보 및 직접 학습할 자세 분류 모델/데이터량/평가 방법
- 이동/이탈 이벤트 정의, 침대 영역 오류 자동 감지 조건, 판정 불가 기준
- 원본 영상 활용/정답 검증 절차, 저장 포맷/주기, 처리 속도와 정확도 목표
- 실제 실험 순서, 반복 횟수, 관찰자 배치/사후 검토 방법, 데이터 접근 및 보관 정책

## 나중에 검토할 기능

- 스마트폰 웹 원격 측정 제어, 모바일 AI 결과 표시/숨김, PC/모바일 역할 분리
- 녹화 영상 재생과 사후 정답 시점 정밀 수정 UI
- 추가 자세 세분화, 이불·신체 가림 대응 및 실사용 환경 확대

## 앞으로의 의사결정 원칙

- 실제 테스트 결과 없는 모델 성능을 단정하지 않음
- 기능을 후순위로 옮기는 것과 합의된 최종 기능을 삭제하는 것을 구분
- 기술을 선정하거나 요구사항을 변경할 때 근거와 결정일을 추가
- 대화/문서에 없는 세부 사양(시간, 정확도, 장비)을 임의로 확정하지 않음

## 2026-10-24 · 문헌 조사 반영 (v0.3)

**완료한 작업:** 참고 논문 25편의 출처, 방법, 실험 조건, 한계와 적용점을 별도 [문서](LITERATURE_REVIEW.md)로 정리. 기존 설계 목표는 유지하고 실증·평가 제안을 보강함.

**실험 설계 제안 — 기술 선정 확정 아님:**

- MediaPipe Pose·YOLO Pose·RTMPose를 같은 저장 영상에서 우선 비교하고 MoveNet은 후보 유지.
- 신체 중심 정규화 특징과 침대 상대 위치를 함께 보존. 자세·침대 관계·이탈/복귀 이벤트를 분리.
- 단순 특징 분류/상태 전이 기준선을 먼저 만들고 LSTM/TCN, 그래프 모델의 추가 이득을 검토.
- 참가자·세션 분리, 원본 시각 보존, 판정 불가 비율과 이벤트 오경보를 포함한 평가.
- 저조도 IR·깊이 카메라 연구의 성능을 RGB 카메라 성능으로 대체하지 않음.
- 공개 데이터 접근 가능성, 실제 사람 검출기 사용 여부, 시뮬레이션과 실제 영상의 차이를 명시.

**환경 논의 보충:** 개발 OS는 Windows 기준으로 논의 중이며 CPU/GPU/RAM은 미확인. 스마트폰 카메라 입력의 Android/iPhone·USB/Wi-Fi 방식은 후보로 검토할 수 있으나 선정 전. 스마트폰 **웹 원격 제어**는 기존대로 보류.

**미완료:** 모델 실행·학습·데이터 수집·성능 검증·센서 연동. 이번 문서 갱신을 해당 작업의 완료로 해석하지 않음.
