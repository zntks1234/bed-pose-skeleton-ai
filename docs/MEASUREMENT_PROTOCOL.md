# 측정 절차 초안
## 공통
1. 실험 식별 정보, 촬영 조건 및 녹화 여부 설정
2. 침대 영역 확인 및 필요 시 보정
3. 실시간 분석·기록 시작
4. 계획 측정 진행 또는 자유 자세 관찰
5. 종료 후 정답 검증 여부 및 녹화 구간 확인

## 계획 측정
단일 자세 반복 측정 또는 여러 자세의 순차 측정을 구성합니다. 예시 순서는 누움 → 옆으로 누움 → 걸터앉음 → 이탈 → 복귀이며 최종 시나리오는 실험 목적에 따라 정합니다.

자세마다 준비시간을 개별 설정하는 방식과 사용자가 준비 완료 버튼을 누르는 방식을 모두 지원합니다. 자동·수동 진행 및 전환을 지원하는 방향이며 세부 동작은 구현 시 설계합니다.

## 전환 구간
자세 유지 정확도 평가에서는 준비·전환 구간을 평가에서 제외할 수 있습니다. 침대 이탈·복귀 실험에서는 전환 과정 자체가 분석 대상이므로 기록하고 평가 범위를 명시합니다.

계획된 자세는 실제 수행을 보증하지 않습니다. 관찰 또는 녹화 검토로 확인한 정답을 별도 관리합니다. 관찰과 녹화가 없는 데이터는 정답 미검증 상태로 구분합니다.
