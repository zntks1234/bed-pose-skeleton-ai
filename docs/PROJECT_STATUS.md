# 프로젝트 진행 현황 및 대외 공유용 소개

**기준일:** 2026-10-24 · **기획 기준선:** v0.3 · **상태:** 요구사항/구조 설계 중, 구현 전

## 프로젝트 개요

'카메라 기반 스켈레톤 인식을 활용한 침대 자세 및 움직임 분석 AI 시스템'은 카메라 영상에서 인체 관절을 추정하고 침대 위 자세, 자세 변화, 이탈·복귀를 실시간으로 분석하는 독립적인 측정 시스템을 목표로 합니다.

별도 개발자의 ToF·mmWave 자세 인식 결과를 같은 시간대에 비교하는 **2차 보조 검증**이 주된 사용 목적일 가능성이 높습니다. 구체적인 검증 범위는 외부 개발자와 확인해야 합니다. 두 시스템의 결과가 같다는 사실만으로 정답임을 보장하지 않으므로, 필요 시 실제 수행 자세를 확인한 기준 데이터도 함께 사용합니다.

## 논의로 정리한 개발 방향

- **실험 환경:** 통제된 침대 환경에서 시작. 침대 배치·출입 방향·카메라 종류/각도는 미정이며 공간은 좁을 가능성이 있음. 이불 가림 대응은 초기 우선순위가 낮음.
- **분류 후보:** 누움, 옆으로 누움, 걸터앉음, 일어남(침대 이탈 의미). 외부 센서의 확정 사양이 아닌 잠정 기준.
- **핵심 분석:** 실시간 스켈레톤 및 자세 분류, 자세 변화, 침대 이탈·유지·복귀, 인식 실패 구분.
- **침대 영역:** 최초 자동 인식 후 유지, 오류 시 자동 재인식 또는 사용자 즉시 수동 보정하는 목표 기능.
- **측정:** 단일/순차 계획 측정, 자동/수동 진행, 자세별 준비 시간, 준비 완료 입력을 모두 지원하는 방향.
- **기록:** 시간·스켈레톤·예측·이벤트·영역 이력, 원본 영상은 선택적으로 녹화(시작 시 선택, 진행 중 시작/중지).
- **실험 시나리오:** 사람이 의도한 자세를 순서대로 취하고 동시 측정하는 방식이 유력하나 **미확정**. 자유 측정도 고려.
- **보류:** 스마트폰 웹 원격 제어 및 모바일 표시/숨김, 일부 사후 라벨링·실사용 환경 확장.

## 현재 진행도

**완료:** 프로젝트 목표·개발 범위·주요 기능과 측정 방식에 관한 *기획*, 시스템 구조 및 문서 초안, 참고 논문 25편 조사와 문헌 기반 실증·평가 계획 보강.

**진행 전:** 카메라/개발 환경 확정, 포즈 모델 비교, 스켈레톤 데이터 취득, 자세 분류 AI 학습, 동작 코드, 외부 센서 연동 및 성능 실증.

구체적 개발 일정과 모델 정확도는 아직 제시하지 않습니다. 실제 성능은 통제된 침대 실험으로 확인해야 합니다.

## 다음 단계

1. 외부 개발자와 공통 분류/데이터 전달/검증 목적을 확인
2. 실제 촬영 환경에서 스켈레톤 추정 기술 후보를 비교
3. 독립 실시간 자세 측정기 및 데이터 기록 구현
4. 센서와 동시 측정한 결과의 일치도·변화 시점 비교
5. 실험 결과에 따라 자동화 및 부가 기능 고도화

상세 작업은 [개발 로드맵](../ROADMAP.md)을 참조합니다.

- 관절 추정 후보를 동일 저장 영상에서 비교하는 계획과 단순 분류/상태 전이 기준선에서 시작하는 개발 방향.
- 신체 정규화와 침대 상대 위치의 병행, 미검출·판정 불가 기록, 참가자·세션 분리 및 이벤트 평가 제안.

문헌의 보고 성능은 이 프로젝트에서 재현한 결과가 아닙니다. 모델 선정과 구현은 실제 환경의 기술 실증 후 진행합니다.
