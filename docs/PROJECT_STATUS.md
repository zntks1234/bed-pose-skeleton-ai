# 진행 현황 및 공유용 소개
작성일: 2026-10-24

현재 카메라 기반 스켈레톤 인식을 활용한 침대 자세 및 움직임 분석 AI 시스템을 기획하고 있습니다. 카메라의 신체 관절 정보를 AI로 분석하여 실시간 자세, 자세 변화, 침대 이탈과 복귀를 측정하는 것이 목표입니다.

별도로 개발되는 ToF·mmWave 센서 시스템과 같은 대상을 측정하고 결과를 비교합니다. 카메라 예측 자체를 정답으로 간주하지 않으며 관찰 또는 영상 검토로 확인한 실제 정답을 별도로 관리합니다.

현재 목적, 주요 기능 요구사항, 계획 측정 방식, 선택적 영상 녹화, 데이터 기록과 비교 검증의 기본 흐름을 정리했습니다. 아직 실행 가능한 프로그램이나 학습 모델은 구현되지 않았으며 측정 성능도 검증되지 않았습니다.

향후 카메라 설치 조건과 PC 환경을 확인하고 침대에 누운 사람과 가장자리에 앉은 사람을 안정적으로 추정할 수 있는 기술을 비교합니다. 이후 스켈레톤 추출, 학습 데이터 수집, 자세 분류 모델, 측정·기록 기능을 단계적으로 구현할 계획입니다.

초기에는 이불 가림을 우선 고려하지 않는 통제된 실험 환경에 집중합니다. 스마트폰 웹 원격 제어는 보류된 확장 아이디어입니다.
