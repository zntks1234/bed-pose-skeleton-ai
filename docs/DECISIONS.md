MediaPipe는 현재 실험용 어댑터입니다. 최종 모델 선정이나 다른 후보 대비 우월성의 합의가 아닙니다. [후보 비교](research/TECHNOLOGY_CANDIDATES.md)와 동일 조건 실험 원칙을 유지합니다.

2026-10-30 사용자는 CLIP으로 구현하도록 요청했습니다. **CLIP ViT-B/16을 첫 실험용으로 연결**하며 최종 모델 선정이나 침대 정확도 우월성의 합의는 아닙니다. 추가 학습 없이 RGB를 사용하고 실루엣은 보조 유지, 초기 상태/방향 점수 정책은 미검증으로 기록합니다. 사전학습 자산과 실제 영상 평가는 별도입니다. [구현 계약](design/AUTOMATIC_POSTURE.md).

## 제안·운영 해석

- **복귀:** 다시 걸터앉으면 복귀로 보는 방향으로 대화를 진행했지만 세부 완료 경계는 미확정입니다. 바로 올라가 눕는 경로 포함은 제안입니다.
- **단일 대상:** 관절 이동 기반 잠정 추적과 수동 재지정이 구현되어 있으나 다인 환경의 검증된 동일인 식별은 아닙니다.
- **시간적 상태:** 안정/변화 후보/보류와 이벤트 확인 시간을 나누는 설계는 제안입니다. 현재 프레임별 자동 자세 규칙과 구분합니다.
- **외부 비교:** 두 시스템의 일치·불일치와 변화 시점 비교가 유력하며, 정답 기반 정확도 포함 범위는 외부 개발자와 확인해야 합니다.

## 미정 사항

촬영 위치·높이·화각과 우선 지원 환경, 자세/이벤트 주석 경계, 외부 센서 라벨·출력 형식·시계와 동기화, 허용 지연/정확도 목표, 반복 횟수·대상/세션 분할, 실제 녹화·보관 기간·삭제 정책을 구체화해야 합니다. 현재 개발용 기록 형식이 최종 센서 교환 형식으로 확정된 것은 아닙니다.

## 보류 사항

스마트폰 웹 원격 제어·모바일 AI 표시/앱 전환, 사후 정답 수정 UI, 좌우·엎드림 세분화, 같은 자세 내 팔다리 움직임, 이불 대응 고도화와 실사용 확대입니다. 휴대폰을 PC 웹캠 입력으로 쓰는 것과 원격 조작은 별개입니다. 저장 영상의 단일 프레임 대조는 구현됐으며 연속 재생·정답 편집과 구분합니다.

## 변경 관리

새 결정에는 날짜·사용자 근거·대안·미해결 조건을 남깁니다. 상태는 PROJECT_STATUS, 다음 순서는 ROADMAP, 사용법/기술 계약은 해당 상세 문서, 과거 변경 과정은 archive에서 관리합니다. 새 작업마다 같은 진행 문단을 여러 문서에 반복해서 붙이지 않습니다.

2026-10-29 사용자의 문서 정리 요청에 따라 목적별 폴더·목차·현재 상태 요약·과거 원문 보존으로 구조를 정리했습니다. 기존 기술 결정과 미확정 조건을 새로 확정한 작업은 아닙니다.

## 설치 시점 자유도 · 2026-10-29

사용자 요청: “카메라의 시점에 대해서 특정 위치 방향이 종속되지 않고 자유로웠으면 좋겠어”. 특정 측면·머리/발 방향·높이를 필수 배치로 고정하지 않고, 사용자가 사선/위 시점을 매번 선택하지 않는 사용 흐름을 목표로 합니다. 기존의 세션별 배치 변경 허용을 명시적으로 확장한 요구입니다. 세션 중 이동 카메라 지원까지 합의한 것은 아니며 고정 조건을 유지합니다.

카메라 시점/침대 관계를 자동 처리하는 방법·추가 보정 필요성·지원 가능한 가시 범위·성능 목표는 미정입니다. 몸통 기준 특징·침대 상대 관계·추정 3D/영상 단서의 활용은 설계 후보이며 채택·실증 완료가 아닙니다. 관찰 불가능한 상태는 보류하며, 모든 위치에서 같은 정확도를 보장한다는 뜻은 아닙니다. [현재 의존성과 개선 설계](design/ARCHITECTURE.md#시점-자유도를-높이는-설계-제안).

2026-10-29 구현 요청에 따라 침대 면/추정 3D 대응의 자동 모드 0.6을 연결했습니다. 사용자가 이전 기록 비교를 필수로 요구하지 않는다고 명시했으므로, 이전 방식과 비교 가능성은 구현의 필수 완료 조건에서 제외합니다. 유지 비용 없이 남아 있는 이전 모드는 선택 사항입니다. 실제 시점 일반화 검증 조건은 유지합니다.

## 단독 동작과 선택적 비교 · 2026-10-30

사용자는 카메라 단독으로도 제대로 작동해야 한다고 명시하고, 입력 영역 품질·느린 처리에 따른 추적 보류·오류 구분·불필요한 실루엣 처리의 우선 보완을 요청했습니다. 카메라 분석·기록은 센서 연결 없이 동작하며 비교는 독립 결과를 선택적으로 연결합니다. 실루엣은 입력별 진단 선택으로 전환합니다. CLIP 자세 선택 점수는 유지하고 입력 품질 정책은 미검증 실험 버전으로 추적합니다.

### 2026-10-30 · 두 시점 통합과 실행 장치 독립성

사용자는 두 카메라의 통합 자세 판정 구현을 요청했고, 향후 Mac 사용 가능성을 고려해 특정 컴퓨터 사양에 종속시키지 말 것을 재확인했습니다. 영상 근거 결합은 모델 실행 장치와 분리합니다. 균등 점수 결합·단일 시점 대체는 초기 구현 정책이며 정확도 우위나 최종 모델 선정이 확정된 것은 아닙니다.


2026-10-31 사용자는 기존 CLIP을 유지하면서 계측→선택적 CUDA 혼합 정밀도→모델 공유→전처리/전송→묶음 추론 순으로 최적화하도록 요청했습니다. CPU/Mac 경로와 FP32 비교 실행을 유지합니다. 실제 장치·정답 비교 전 FP16/묶음은 기본 활성화하지 않으며, 새 추론 엔진 도입은 비교 근거 확보 후 검토합니다.
