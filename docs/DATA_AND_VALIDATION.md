# 데이터 및 비교 검증
## 저장 방향
- 스켈레톤 관절 좌표 및 추정 신뢰도
- 시각·프레임 정보
- AI 자세 분류 결과
- 자세 변경·침대 이탈·복귀 이벤트
- 침대 영역 및 변경 이력
- 실험 설정과 녹화 구간 정보

모든 처리 프레임의 스켈레톤 기록과 별도 이벤트 기록은 추천안입니다. 파일 형식, 저장 주기 및 항목은 확정하지 않았으며 용량·처리 성능을 검증해야 합니다.

## 반드시 구분할 데이터
| 구분 | 의미 |
|---|---|
| 계획 자세 | 실험자가 수행할 목표 |
| 카메라 AI 예측 | 카메라로 독립 추정한 결과 |
| 검증된 실제 정답 | 관찰 또는 영상 검토로 확인 |
| 외부 센서 결과 | ToF·mmWave 시스템의 판단 |

정답 검증 여부와 출처를 관리합니다. 학습 데이터와 평가 데이터를 분리하며 구체적인 분리 기준과 수집량은 미정입니다.

## 검증
공통 자세 기준과 시간 정렬 방식을 합의한 뒤 자세 정확도, 오분류, 결과 불일치, 자세 변화·이탈·복귀 감지 시점 차이를 평가합니다. 시계 오차와 실제 처리 지연을 구분해야 합니다. 정확도·처리속도·허용 지연 목표는 미정입니다.

원본 영상은 필요할 때만 녹화합니다. 참여자 동의, 보관 기간과 접근 권한을 실험 전에 정합니다. 원본 영상과 참여자 정보는 소스 저장소에 올리지 않습니다.
