# 카메라 기반 침대 자세·움직임 분석 AI

카메라 영상에서 스켈레톤과 자세·이탈·복귀를 분석하고, 외부 ToF·mmWave 시스템의 독립 측정 결과와 같은 시간대에 비교하는 프로젝트입니다.

> **현재 단계 · 2026-10-26**  
> 기획·설계 초안과 문헌 정리를 마쳤습니다. 모델·장비는 미선정이며, 코드 구현·학습·성능 실험은 시작 전입니다.

## 전체 구조 한눈에 보기

![카메라 AI와 외부 센서가 독립 분석한 결과를 시간·라벨로 정렬해 비교하고, 실제 정답이 있는 구간에서는 각각의 정확도를 평가하는 설계 구조](docs/assets/system-overview.png)

카메라 분석과 외부 센서 분석은 독립적으로 진행합니다. 두 결과의 **일치도 비교**와 실제 정답에 대한 **정확도 평가**를 구분합니다.

[그림 크게 보기](docs/assets/system-overview.png) · [상세 시스템 구조](docs/ARCHITECTURE.md)

## 현재까지 정리한 것

| 항목 | 상태 |
|---|---|
| 목적·기능·측정 흐름 | 기획 및 설계 초안 작성 |
| 참고 논문 | 29편: 침대 자세 17편 + 스켈레톤 기술 12편 |
| 원문 확인 | 26편 본문 대조, 3편 본문 미확보 |
| 기술 후보 | 비교 기준·적용 방법 정리, 실제 비교 전 |
| 다음 우선 과제 | 외부 센서 사양·촬영 환경 확인, 같은 영상으로 후보 비교 |

문헌의 보고 성능과 프로젝트 자체 실험 결과는 구분합니다. **자체 성능 결과는 아직 없습니다.**

## 개발 방향

- 통제된 침대 환경에서 시작합니다. 잠정 자세는 누움·옆으로 누움·걸터앉음·일어남이며, 최종 라벨은 외부 개발자와 확인합니다.
- 관절 추정, 자세 분류, 침대 점유 상태, 이탈·복귀 이벤트를 구분합니다.
- 카메라 AI는 외부 센서 결과나 목표 자세를 예측 입력으로 사용하지 않습니다.
- 두 시스템의 일치도와 실제 정답 기준 정확도는 별도로 평가합니다. 최종 비교 범위는 협의 전입니다.
