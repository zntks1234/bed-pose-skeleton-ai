# 측정 절차 및 정답 확인 방식 (v0.3)

## 확정 요구와 아직 확인할 점

- **합의된 기능 방향:** 자유 실시간 분석, 계획 측정(단일 자세/순차 자세), 자동·수동 진행, 자세별 준비 시간, 준비 완료 버튼, 선택적 녹화.
- **유력하지만 미확정 실험 방식:** 참가자가 '누움 → 옆으로 누움 → 걸터앉음 → 침대 이탈 → 복귀' 등의 목표 동작을 순차 수행하며 카메라와 ToF·mmWave가 동시에 측정. 구체적 순서와 자세 정의는 외부 개발자와 추후 확인.
- **운영 조건:** 별도 관찰자가 있을 때와 없을 때 모두 가능해야 함.

## 공통 실험 절차 (초안)

1. 실험 식별자와 촬영 조건을 기록하고 원본 영상 녹화 여부 선택
2. 카메라/침대 영역을 확인하고 필요하면 자동 재인식·수동 수정
3. 두 시스템의 측정 시간 기준 확인
4. 자유 분석 또는 목표 자세를 정한 계획 측정 모드 시작
5. 준비/전환/자세 유지·동작 측정 구간을 구분하여 분석 결과 기록
6. 계획 라벨, 카메라 예측, 센서 결과를 각각 독립적으로 저장
7. 실제 자세/이벤트 발생 시각을 검증할 수 있으면 확인하고 검증 상태 기록

## 단일 자세 계획 측정

- 목표 자세를 선택하고 준비 후 측정
- 동일 자세 여러 회 반복 가능
- 준비 완료 버튼이나 설정된 시간에 따라 측정 구간 시작
- **목표 자세 = 예정 라벨**이지 검증된 실제 정답이 아님
- 관찰 또는 영상 검토로 확인한 경우 검증된 정답으로 승격

## 순차 계획 측정

- 여러 목표 자세/동작을 미리 등록하며 순서와 준비 시간 지정
- 시간 기반 자동 진행 및 수동 진행 모두 지원; 일시정지, 재개, 단계 재측정 가능
- '준비 → 전환 → 측정 → 다음 단계' 구간을 명시
- 자세 유지 분류 평가는 준비·전환 구간을 제외할 수 있음
- **침대 이탈/복귀의 전환 동작은 평가 대상**이므로 반드시 측정 결과와 시각을 남김
- 버튼을 누른 시각은 사용자의 조작 시각이지 반드시 실제 동작 시작 시각이 아님

## 관찰자 유무에 따른 정답 기록

| 조건 | 계획 자세 | 정답 확인 방식 |
|---|---|---|
| 관찰자 있음 | 실험 전 지정 | 관찰자 실시간 입력 후 필요 시 재검토 |
| 관찰자 없음 + 영상 녹화 | 실험 전 지정 | 녹화 영상에서 사후 확인 가능 |
| 관찰자 없음 + 영상 미녹화 | 실험 전 지정 | 계획 라벨만 존재할 수 있음; 정답 **미확인** |

라벨 상태는 미확인 / 임시 기록 / 검증 완료 등으로 나눌 수 있음. 사람의 눈으로 확인해도 애매한 상황은 불확실로 남길 수 있어야 함. AI 예측을 정답으로 자동 전환하지 않음.

## 실험 결과 해석

- 두 시스템의 판단이 같음 → **교차 일치**, 실제 정답인지는 별도 문제
- 계획 자세와 AI 예측이 같음 → **계획 대비 일치**, 실제 정답인지는 별도 문제
- 검증된 실제 자세와 AI 판단이 같음 → 해당 구간의 **정답 기준 판정**
- 상태 유지 자세의 정확도와 이탈/복귀 이벤트 발생 시점 비교는 다른 평가 항목

## 미정

준비 시간 기본값, 구간 종료 규칙, 시계 동기화 방법, 반복 횟수, 정답 확인 담당, 이벤트 허용 시간 오차, 촬영·동의 방식.

## 문헌에 근거한 실증 시나리오 보강안

현재 잠정 라벨을 바꾸지 않고, 오검출을 설명할 수 있는 비교 상황을 수집하는 제안입니다. 횟수·유지 시간·자세 순서는 아직 확정하지 않습니다.

| 목적 | 비교할 상황 | 기록할 항목 |
|---|---|---|
| 정적 자세 | 바로 누움, 옆으로 누움, 걸터앉음 | 실제 확인 자세, 관절 누락·신뢰도 |
| 이탈과 단순 움직임 구분 | 몸만 일으키고 다시 눕기, 앉은 채 유지, 실제 이탈 | 전환 시작·완료 시각, 침대 관계 |
| 이탈 후 복귀 | 침대 밖 유지 후 돌아와 앉기/눕기 | 이탈 상태 유지와 복귀 전환 |
| 인식 실패와 이탈 구분 | 화각 경계·일시 가림·관절 추정 실패 | 실제 위치, 미검출 원인·지속 시간 |
| 후속 가림 실험 | 가림 없음/부분 가림/이불 | 입력 장비·가림 정도별 별도 결과 |

같은 저장 영상을 후보 모델에 입력해 비교한 뒤 실제 카메라 경로의 전송·처리 지연을 측정합니다. 외부 센서와 비교할 때는 원본 시각 및 공통 이벤트 기준을 사용합니다.

정답 검토자는 가능하면 카메라·센서 예측을 보지 않고 실제 수행 내용을 먼저 기록합니다. 관찰자가 없는 실험에서 준비 완료 버튼이나 계획 라벨만으로 실제 정답을 확정하지 않습니다. 사후 영상 정답 수정 UI의 개발 여부는 기존대로 미정입니다.
