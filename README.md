# 카메라 기반 스켈레톤 침대 자세·움직임 분석 AI

**프로젝트 상태:** 기획 및 시스템 설계 (v0.2, 2026-10-24) · **구현 전**

침대 위 사람의 자세와 움직임을 카메라 영상에서 독립적으로 분석하고, 외부 ToF·mmWave 센서의 결과와 **동일 시간대에 비교하는 실시간 보조 검증 시스템**을 개발하는 프로젝트입니다.

> **현재 유력한 목적은 두 시스템의 결과 교차 확인(일치·불일치 및 변화 시점 차이)입니다.** 실제 정답을 이용한 각 시스템의 정확도 평가는 보완적인 검증 방법입니다. 외부 개발자와 최종 검증 범위는 아직 확인되지 않았습니다. **카메라 AI의 예측이나 두 시스템의 일치가 실제 정답을 의미하지는 않습니다.**

## 개발 목표

- 카메라에서 실시간으로 인체 스켈레톤을 추정하고 이를 활용해 자세를 분류
- 침대 이탈 발생, 이탈 상태 및 복귀 과정 분석
- 프레임별 시간과 분석 결과 기록, 판정 불가 구간 분리
- 외부 ToF·mmWave 시스템이 생성한 결과와 공통 자세 기준 및 시간으로 비교
- 통제된 실험에서 사전 계획 자세와 실제 검증된 정답을 구분하여 기록

### 초기 자세 분류 후보

| 구분 | 의미 | 비고 |
|---|---|---|
| 누움 | 바로 누운 상태 | 잠정 |
| 옆으로 누움 | 측면으로 누운 상태 | 잠정 |
| 걸터앉음 | 침대 가장자리에 앉은 상태 | 잠정 |
| 일어남 | 침대에서 벗어나는 동작 또는 이탈 상태 | 잠정; 상태·이벤트 구분 필요 |

외부 센서의 최종 분류 사양은 확인 전입니다. 추후 자세 항목을 추가할 수 있는 구조를 지향합니다.

## 개발 범위와 우선순위

**최초 동작 목표(MVP):**
1. 통제된 침대 환경의 카메라 영상에서 스켈레톤을 안정적으로 추출할 수 있는지 검증
2. 기본 자세를 독립적으로 인식하고 이탈·복귀를 판단할 수 있는 실시간 측정기 구현
3. 촬영 시각, 스켈레톤, 자세·이벤트 결과 및 판정 불가 기록
4. 외부 센서 결과를 받아 동시 측정 구간의 일치·불일치 및 감지 시점 비교

**합의된 최종 기능이지만 순차 구현:** 침대 영역 최초 자동 인식 및 오류 시 자동 재인식·즉시 수동 보정, 단일·순차 계획 측정, 자동·수동 진행, 자세별 준비 시간·준비 완료 확인, 선택적 영상 녹화 및 시작·중지 조작.

**추가 검토(확정 아님):** 스마트폰 웹 원격 제어, 모바일 AI 결과 표시/숨김, 사후 영상 라벨링 UI, 이불로 인한 신체 가림 대응.

## 현재 진행 상태

- 완료된 것: 프로젝트 목적·책임 분리·기본 요구사항·구조 초안·단계별 개발 우선순위 **기획**
- 아직 완료되지 않은 것: 카메라/PC 선정, 스켈레톤 모델 비교, AI 분류 모델, 코드 구현, 학습 데이터 수집, 성능 검증, 외부 센서 연동
- 실험 환경: **통제된 침대 환경 우선**. 공간은 좁을 수 있으며 침대 배치·카메라 위치는 미정. 실제 환경 확장과 이불 가림 대응은 초기 범위 밖일 가능성이 높음
- 예상 실험 방식: 미리 정한 자세를 순차적으로 수행하고 두 시스템을 동시 측정하는 방식이 **유력하지만 미확정**. 자유 측정 방식도 수용하도록 설계
