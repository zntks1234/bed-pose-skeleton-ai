# 프로젝트 진행 현황

[프로젝트 홈](../README.md) · [로드맵](../ROADMAP.md) · [확정·잠정·보류 사항](DECISIONS.md)

**기준일: 2026-10-27 · 현재 단계: 초기 범위 합의·판정 흐름 설계 제안 · 구현·실측 전**

카메라로 침대 위 자세와 움직임을 독립 분석하고 외부 ToF·mmWave 결과와 비교하는 시스템을 준비하고 있습니다. 일치도와 이벤트 시점 비교가 유력한 주목적이며, 정답 기반 정확도 평가를 포함할 최종 범위는 외부 개발자와 확인해야 합니다.

## 완료한 작업

| 작업 | 현재 산출물 |
|---|---|
| 목적·범위 정리 | 세 가지 초기 자세·자세 변화/이탈/복귀, 독립성, 세션별 설치 변경·세션 중 카메라 고정 |
| 기능·운영 흐름 기획 | 실시간 분석, 단일·순차 측정, 준비 시간·완료 입력, 선택적 녹화 |
| 구조·평가 초안 | 분석 책임 분리, 시간 기록, 정답 관리, 비교 지표 |
| 초기 코드 구성 설계 | [코드 설계 제안](CODE_DESIGN.md): 패키지·입출력·대상/품질 상태·실행 생명주기·기록 실패·평가·검사 범위. 개발용 테스트와 실제 구동 중 품질 검사 구분. 구현 전 |
| 논문 정리 | 침대 자세 24편·스켈레톤 기술 13편, 총 37편 |
| 원문 확인 | 33편의 공개 본문·저자판 관련 절·표 대조; 4편은 **본문 미확인·사실 판단 제외**(P11·P12·P19·P34); P35의 2022 최종 출판본은 **본문 미확인·해당 판본 판단 제외** |

| 기술별 실행 부담 자료 | [연산·실행 부담 비교](POSE_COMPUTE_AND_RESOURCE_COMPARISON.md): 모델별 구조·공개 처리 시간·추가 학습·다중 모델 결합 부담 정리. 자체 성능 측정 아님 |
| AI 작업 안내 | [공통 지침](../AGENTS.md)과 [작업 프롬프트](AI_TASK_PROMPT.md) 작성 |

**완료된 것은 기획·문헌과 실험 계획의 작성입니다.** 기능 구현이나 논문 성능의 재현 완료를 의미하지 않습니다. 논문의 수치 불일치·접근 제한은 해당 논문 항목에 표시했습니다. 미확인 본문 4편은 서지 검색 후보로만 남기고 기술 구현·성능 비교·설계의 사실 근거로 쓰지 않습니다. P35의 2022 ACM 최종 출판본도 미확인으로 분리합니다. P31·P35의 판본별·표별 주의사항을 문서에 기록했습니다.

## 이번 기획 검수와 진행 사항 · 2026-10-27

- **사용자 합의:** 초기 3자세, 자세 변화 중심의 움직임 범위, 침대에서 내려와 완전히 서면 이탈 완료, 세션 중 카메라 고정.
- **운영 해석·제안:** 걸터앉으면 복귀로 해석한 대화 경위와 미정 조건, 단일 대상 선택·추적, 안정/변화 후보/판정 보류, 이벤트 시각 분리를 문서화했습니다. 확정 상태는 [결정 사항](DECISIONS.md)을 따릅니다.
- **검수에서 찾은 과제:** 관절 모델의 최종 선정 시점 통일, 침대 영역 의미·대상 관리·품질 검사 책임, 측정 조작과 장애 처리, 주석 지침·완료 기준 구체화.
- **다음 설계 제안:** 1단계는 후보 압축·잠정 선택, 자세/이벤트 기준선과 연결한 평가 후 최종 선정. [로드맵](../ROADMAP.md)에 제안으로 반영했습니다.
- 이번 갱신은 설계 진행 기록입니다. 코드·영상 수집·모델 실행·새 논문 원문 검증·성능 실험은 수행하지 않았습니다.

## 다음 할 일

1. **외부 사양 확인:** 비교 목적, 합의한 카메라 범위와 센서 라벨·이벤트 매핑, 센서 출력, 시간 정렬 방식.
2. **촬영 조건 확인:** 세션별 침대 배치·출입 방향·카메라 위치·화각 기록 및 세션 중 고정 확인. 대상 겹침·미검출 처리와 판정 흐름의 세부 규칙도 검토합니다.
3. **비교 자료 준비:** 세 가지 자세, 자세 전환, 이탈·복귀 및 주변 인물 등장·겹침이 담긴 비교 영상을 확보합니다.
4. **비교 러너 구현·후보 실증:** [실험 계획](POSE_BENCHMARK_PLAN.md)에 따라 동일 영상·프레임으로 MediaPipe Pose Landmarker·YOLO Pose·RTMPose를 비교하고 MoveNet을 대안으로 둡니다. 실제 관절 품질과 전체 지연을 각각 측정합니다.

**현재 미정:** AI 추론의 실행 위치·방식은 아직 결정하지 않았습니다. 기술 후보는 실제 인식 결과를 바탕으로 비교하고 효율적인 구현·지연 최소화는 개발 과정에서 지속적으로 고려합니다.

모바일 앱 구현은 가능성 검토 단계입니다. MediaPipe의 추가 기능 활용과 YOLO Pose·RTMPose 병용도 검토 후보이며, 채택된 구현 방식으로 취급하지 않습니다. 누운 자세의 후보별 우열은 실증 전이며, [기술 후보 비교](TECHNOLOGY_CANDIDATES.md#open-questions)에 남은 확인 항목을 정리했습니다.

외부 협의와 촬영 환경 조사는 병행할 수 있습니다. 모델 채택, 일정, 정확도·지연 목표는 실증과 협의 후 정합니다.
