## 공통 기반 구현 착수 · 2026-10-27 (이전 단계)

`src/bed_pose`에 프레임 식별 데이터형, 엄격한 JSON 설정 로딩·스키마 검사·상대경로 해석, 순차 프레임 ledger 프로토타입을 추가했습니다. 개발용 unittest 4개로 중복 JSON 키, 프레임 순서, 실패 실행의 기록 완결성, 미완료 상태 유지를 확인했습니다.

이 당시 ledger의 `frames.jsonl`은 기반 검사용 프로토타입 형식이었습니다. 이후 정식 FrameResult·원본/공통 참조와 영상·합성 어댑터를 연결한 범위는 아래 후속 기록을 따릅니다. 실제 SDK·평가·시각화는 미구현입니다. 설치된 개발 환경에서 `PYTHONPATH=src python -m unittest discover -s tests -v`로 검사했습니다. 모델 성능 검증이 아닙니다.

설정 로더의 가상 설정 파일에 대한 스키마 검사·설정 파일 기준 상대경로 해석도 별도 확인했습니다. 실제 입력 파일 존재·자산 해시 검증과 패키지 설치 검증은 아직 수행하지 않았습니다.

## 저장 영상·정식 기록·합성 어댑터 연결 · 2026-10-27

- `prepare`, `run`, `demo`, `inspect` CLI를 구현했습니다. 원본 PTS·time base·픽셀/파일 해시, 회전·색상 규약을 고정해 영상을 다시 읽고 확인합니다.
- `ResultRecorder`는 패키지에 포함된 FrameResult 스키마, 원본/공통 결과 참조·후보/관절 수·쓰기 시간·최종 파일 해시를 검사합니다. SDK용 시각은 추론 실패에도 보존합니다. 실행 실패와 기록 완결성은 별도 상태입니다.
- 합성 어댑터는 후보 0명·다인·관절 누락·오류 주입을 지원하고 모든 실행을 synthetic으로 표시합니다. 실제 어댑터 이름은 합성으로 자동 대체하지 않고 거부합니다. 대상 자동 선택·추적·품질 점수 임계값은 도입하지 않았습니다.
- 개발 검사 29개를 통과했습니다. 정상 6프레임, 가변 간격 PTS, 90도 회전, 매핑 실패의 원본 보존, 실패 후 미처리, 저장/정리 실패, 입력·결과 변조, 패키지 스키마 일치 등을 확인했습니다. 임시 생성 영상·테스트 출력만 사용했습니다.
- Linux/Python 3.12에서 editable 설치를 확인했습니다. PyAV 18.1.0(고정)·NumPy·jsonschema를 의존성으로 선언하며 PyAV 요구에 따라 Python 최소 버전은 3.11입니다. 최종 AI 실행 위치·장비 선정과 별개입니다. Windows 실제 실행과 침대 영상 성능은 미검증입니다.
- 후속 작업: 실제 모델 어댑터 하나의 공식 API·자산·라이선스·좌표 profile 확인 및 연결, 정답 주석 기반 평가, 오버레이/실시간 입력. 현재는 코드 실행 경로 확인이며 사람/자세/이탈 인식 성공이 아닙니다.

배포용 wheel 빌드·설치 후 저장소 밖 임시 디렉터리에서 demo/inspect를 실행했습니다. 정상 6프레임과 오류 주입(정상 2·실패 1·미처리 3, 종료 코드 3)의 무결성을 확인했습니다. 패키지에 스키마가 포함되고 개발용 tests 디렉터리가 포함되지 않는 것도 확인했습니다. 이는 Linux 개발 환경에서의 패키징·실행 경로 검증입니다.

## MediaPipe 어댑터 구현·재검사 · 2026-10-27

사용자가 로컬 테스트를 수행할 수 없어 개발 환경에서 기존 29개 검사를 재실행했습니다. 다음 단계로 선택 의존성 MediaPipe 0.10.35의 IMAGE/VIDEO 어댑터와 설정 CLI를 추가했습니다. 자산/옵션 해시·33→17 매핑·원본 필드·시간 순서·재생성 reset·SDK 호출 여부 기록을 연결했습니다. SDK 경계 모의 검사 10개를 추가해 전체 39개를 통과했습니다. 매핑 오류가 나도 이미 호출한 SDK 여부를 보존하도록 보완했습니다.

실제 SDK 설치·RGB Image·landmark 필드·옵션 및 잘못된 모델 거부를 확인했습니다. Linux native 로딩에 필요한 GLES 라이브러리 누락을 임시 개발 환경에서 보완했습니다. 공식 모델 다운로드가 HTTP 403으로 실패하여 **유효 모델 추론 성공·모델 자산 사용 조건·침대 성능은 미검증**입니다. 실제 모델 등록 게이트를 통과한 것으로 처리하지 않습니다. [상세 근거·명령·제약](MEDIAPIPE_ADAPTER.md).

0.3.0 wheel을 빌드·설치해 저장소 밖에서 합성 demo/inspect, MediaPipe 설정 생성, 실제 SDK의 잘못된 모델 실패 및 전체 미처리 ledger 무결성을 확인했습니다. 이는 유효 모델 추론 성공을 의미하지 않습니다.
