# 카메라 기반 침대 자세·움직임 분석 AI

카메라 영상으로 침대 위 사람의 관절과 자세를 분석·기록하고, 향후 ToF·mmWave의 독립 측정 결과와 비교하는 프로젝트입니다.

**현재 단계: 실제 침대 영상 평가 준비.** 기본 0.7은 신체 형태 후보와 침대의 영상상 관계를 따로 계산합니다. 실제 누움·앉음 확정은 후속이며, 이전 0.6의 세 자세 예측은 비교 모드로 유지합니다. 관절·자세의 정답 기반 정확도는 미검증이며, 이탈·복귀 판정은 미구현입니다.

## 시작하기

이미 설치한 환경에서는 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
& .\.venv\Scripts\python.exe -m bed_pose live
```

**입력 추가 → 카메라/영상 선택 → 필요 시 침대 모서리 네 점 지정 → 측정 시작 → 측정 종료** 순서입니다. 종료할 때는 ‘작업실 종료’ 또는 Ctrl+C를 사용합니다. 브라우저 탭만 닫으면 측정은 계속됩니다.

## 무엇을 할 수 있나요?

| 기능 | 현재 범위 |
|---|---|
| 입력 | 이름으로 카메라 선택, 해상도·FPS 요청, 저장 영상 분석, 여러 입력 동시 표시 |
| 분석 | 관절·실루엣, 독립 신체 형태 후보·침대 관계·적합도. 최종 자세 확정과 구분 |
| 측정 | 선택적 네 점 영역과 개별 형태 기록, 두 입력 그룹의 단일 계획 측정 |
| 기록 검토 | 기록 목록·시간축·프레임별 근거, 원본 저장 영상과 정확한 프레임 대조 |
| 두 카메라 | 운영자 동일인·수신 시각 검사. 기존 예측 라벨 일치는 유지하며 0.7 후보를 확정 라벨로 결합하지 않음 |

두 카메라의 가려진 관절 상호 보완, 노출 동기화·삼각측량, 자세 전환 안정화, 이탈/복귀, 자동 침대 인식, 선택적 카메라 영상 녹화와 외부 센서 비교는 후속입니다.

## 앞으로의 방향

관절 추정 실증 → 독립 자세·이벤트 측정기 → ToF/mmWave 비교 → 운영 기능 완성 순서입니다. 현재는 실제 침대 영상으로 세 자세 기준선을 평가할 준비 단계이며, 자동 침대 인식·선택적 녹화·단일/순차 계획 등 남은 목표도 유지합니다. [전체 로드맵과 단계별 체크리스트](ROADMAP.md)에서 현재 위치·다음 작업·완료 조건을 확인하세요.

## 결과를 해석할 때

- 적합도는 확률이나 정확도가 아닙니다. 현재 0.65 기준과 가중치는 실험 초기값입니다.
- 목표 자세·AI 예측·확인된 정답·외부 센서 결과를 분리합니다.
- 개발 테스트와 기록 무결성 검사는 실제 사람의 자세 정확도 검증을 대신하지 않습니다.
- 원본 영상·개인정보·모델 파일은 GitHub에 올리지 않습니다.
