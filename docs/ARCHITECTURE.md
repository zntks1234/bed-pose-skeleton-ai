# 시스템 구조 초안
구현 기술 및 모듈 경계는 아직 확정하지 않았습니다.

## 기본 흐름
카메라 영상 → 침대 영역 및 스켈레톤 추출 → AI 자세 분류 → 상태·이벤트 분석 → 화면 표시 및 데이터 저장 → 외부 센서 비교

## 책임 분리
- 영상 입력: 프레임과 촬영 시각 관리
- 침대 영역: 자동 추정, 사용자 보정, 변경 이력
- 스켈레톤 추정: 관절과 추정 신뢰도
- 자세 분류: 영상에서 얻은 정보만으로 독립 예측
- 상태·이벤트: 자세 예측의 흔들림과 실제 변화 구분
- 측정 진행: 목표 자세·준비·측정 단계 관리
- 기록: 프레임·예측·이벤트·실험·녹화 구간 연결
- 센서 비교: 시간 정렬 및 공통 분류 매핑

목표 자세와 외부 센서 판단을 카메라 AI의 정답 입력으로 사용하지 않습니다. 원시 센서 데이터 제공 여부 및 이미 분류된 결과 수신 여부에 따른 연결 방식은 미정입니다.

MediaPipe Pose, MoveNet, YOLO Pose, RTMPose는 검토 후보일 뿐 선정된 의존성이 아닙니다. 실제 촬영 조건에서 적합성·성능·개발 난이도를 확인한 뒤 선정합니다.
