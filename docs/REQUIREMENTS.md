# 기능 요구사항
상태: 구현 전 기획 기준선 v0.1

## 분석
- 실시간 카메라 영상에서 스켈레톤을 추출하고 AI가 독립적으로 자세를 분류합니다.
- 분류 후보: 누움, 옆으로 누움, 걸터앉음, 일어남. 최종 정의는 미정입니다.
- 자세 변경, 침대 이탈, 이탈 유지, 복귀를 분석합니다.
- 침대 영역 자동 인식·재인식과 수동 보정을 지원하는 방향입니다.
- 사람 미검출을 곧바로 침대 이탈로 간주하지 않습니다. 판정 기준은 실험으로 정합니다.

## 실시간 화면
카메라·스켈레톤, AI 자세, 침대 영역·점유 상태, 주요 이벤트, 녹화 상태 및 조작을 표시합니다. 세부 배치는 미정입니다.

## 측정
단일 및 순차 계획 측정, 자동 및 수동 진행·전환을 지원하는 방향입니다. 자세별 준비시간 설정과 준비 완료 버튼 방식을 모두 지원합니다. 준비 단계와 실제 측정 단계를 구분합니다.

## 녹화
시작 시 녹화 여부를 선택하고 분석 중에도 시작·중지할 수 있게 합니다. 녹화 중지 후에도 AI 분석과 데이터 기록은 지속합니다. 각 녹화 구간의 시작·종료 시각을 관리합니다.

## 범위
모바일 원격 제어·모바일 결과 표시/숨김·PC와 모바일 역할 분담은 추후 검토입니다. 이불 가림 대응은 초기 우선순위가 낮습니다.
