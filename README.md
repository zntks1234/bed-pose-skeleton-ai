# 카메라 기반 스켈레톤 침대 자세 분석 AI

카메라 영상에서 스켈레톤을 추출하고 침대 자세·움직임·이탈·복귀를 독립적으로 분석하여 ToF·mmWave 센서 결과와 비교 검증하는 실험용 AI 시스템입니다.

## 현재 진행 상황
2026-10-24 기준 기획·설계 단계입니다. 요구사항과 기본 흐름을 정리했으며, 카메라·추정 기술·분류 모델은 미선정입니다. 구현과 성능 검증은 아직 진행하지 않았습니다.

## 개발 방향
- 통제된 침대 실험 환경에서 실시간 스켈레톤 추출 및 AI 자세 분류
- 침대 영역 자동 인식, 재인식 및 수동 보정
- 자세 변화, 침대 이탈·이탈 유지·복귀 분석
- 단일·순차 계획 측정과 자동·수동 진행
- 분석 데이터 상시 기록과 선택적 원본 영상 녹화
- 검증된 실제 정답을 기준으로 카메라·외부 센서 결과 비교

기본 분류 후보는 누움, 옆으로 누움, 걸터앉음, 일어남입니다. 일어남 동작과 이탈 상태의 구분을 포함한 최종 기준은 협의가 필요합니다.
