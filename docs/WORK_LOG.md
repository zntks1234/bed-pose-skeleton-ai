### 유지할 결정과 확인 제한

- 카메라 분석과 외부 ToF·mmWave 분석의 독립성을 유지합니다. 목표 자세·센서 결과를 카메라 예측 입력이나 자동 정답으로 사용하지 않습니다.
- 문헌 33편은 **확인한 판본의 관련 본문 대조 기록**이 있습니다. 최종 출판본 전체 검증이나 자체 재현 완료를 뜻하지 않습니다.
- **P11·P12·P19·P34는 본문 미확인**으로, 서지 후보로만 유지하고 사실 판단·비교·선정 근거에서 제외합니다.
- **P35는 2020 공개판만 본문 확인**, 2022 ACM 최종판은 본문 미확인·해당 판본 판단 제외입니다. P31·P35의 수치·조건 주의사항도 기존 문서에 유지합니다.
- MediaPipe Pose Landmarker·YOLO Pose·RTMPose의 우선 비교와 MoveNet 대안은 **실험 제안**입니다. 모델 채택·성능 순위·AI 추론 실행 방식은 확정하지 않았습니다.

### 오늘 논의한 후속 검토 주제 — 질문과 결정 구분

아래는 대화에서 확인한 질문과 검토 주제입니다. 후속 답변의 구체적인 결론은 확인하지 못했으므로, 저장소에 반영된 결정 범위를 넘어서는 합의나 성능 결론으로 기록하지 않습니다.

| 검토 주제 | 현재 상태와 남은 확인 |
|---|---|
| 모바일 앱 구현 가능성 | 가능성 검토만 진행. 모바일 앱으로 전환하기로 정한 것은 아니며, 스마트폰 카메라 입력 후보와 보류 중인 웹 원격 조작 기능을 구분 |
| MediaPipe의 역할과 다른 기능 활용 | 프레임워크인지, 다른 MediaPipe 기능도 사용하는지 질문. 확인 가능한 기록에서 추가 기능 도입 결정은 확인되지 않음 |
| 누운 자세에서 후보별 인식 차이 | MediaPipe가 다른 후보보다 불리한지 질문한 상태. 실제 동일 영상 비교 전 성능 우열을 확정하지 않음 |
| MediaPipe와 YOLO Pose/RTMPose 병용 | 함께 사용하는 방안을 질문. 확인 가능한 기록에서 결합 구조·채택 결정은 확인되지 않으며 기존 독립 후보 비교 계획은 유지 |
| 개발 관점과 주석 작업량 | 개발 관점의 검토와 주석 작업량의 의미를 질문. 실제 주석 범위·표본 수·작업량은 기존 실험 계획에서도 미정 |

### 다음 작업

1. 외부 개발자와 비교 목적, 최종 자세·이벤트 정의, 센서 출력 형식과 시간 기준을 확인합니다.
2. 촬영 공간·침대·카메라 조건과 촬영 동의·보관 방식을 정한 뒤, 동일 비교 영상을 준비합니다.
3. [비교 실험 계획](POSE_BENCHMARK_PLAN.md)에 따라 입력·관절 추정 어댑터·매핑·기록·평가를 갖춘 최소 러너를 구현합니다.
4. 실제 영상에서 후보별 품질·실패·지연을 비교하고, 실제 정답이 있는 범위에서만 정확도를 평가합니다.
5. 실증 결과와 미해결 질문을 바탕으로 모델과 실행 방식을 결정합니다. 모바일 구현·모델 병용은 채택 전 별도 검토가 필요합니다.

**미실행:** 코드 구현, 모델 실행·학습, 영상 수집·정답 주석, 성능·지연 실측, 외부 센서 연동. 작업 기록 추가는 이 항목들의 완료를 의미하지 않습니다.
