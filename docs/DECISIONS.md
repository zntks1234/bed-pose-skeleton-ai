## 합의한 방향

1. 카메라 AI와 외부 ToF·mmWave는 독립적으로 분석합니다.
2. 통제된 침대 환경에서 시작하고 실제 사용 환경 확장은 추후 검토합니다.
3. 실시간 분석과 결과 기록을 수행하며 원본 영상 녹화는 선택할 수 있습니다.
4. 시작 시 녹화 여부를 정하고 분석 중에도 녹화를 시작·중지할 수 있습니다. 녹화 여부와 분석은 분리합니다.
5. 침대 영역은 최초 자동 인식 후 기본 유지합니다. 오류 시 자동 재인식과 사용자 즉시 수동 보정을 지원합니다.
6. 자세·점유 상태·이벤트를 분리하고 이탈 발생·유지·복귀를 추적합니다.
7. 단일 자세와 여러 자세의 순차 계획 측정을 지원합니다.
8. 자동·수동 진행, 자세별 준비 시간, 준비 완료 입력을 모두 지원합니다.
9. 목표 자세·카메라 예측·센서 결과·확인된 실제 정답을 구분합니다.
10. 필요하면 새 자세 분류를 추가할 수 있도록 설계합니다.
11. **2026-10-26 추가 합의:** 실제 카메라 AI 측정·센서 비교에서는 **로컬 추론을 기본**으로 합니다. 네트워크/클라우드 추론을 기본 가정하지 않습니다.
12. **2026-10-26 추가 합의:** 모델은 침대 환경에 대한 인식 품질과 실증 결과를 근거로 선정하며, 코드의 중복 연산 회피·모듈 분리·지연 관리는 개발 과정에서 지속적으로 고려합니다.

자동 침대 인식과 순차 측정은 최종 목표로 유지합니다. 초기 실증에서는 최소 수동 영역 지정과 단순 측정 조작부터 구현할 수 있습니다.

## 잠정 목적과 분류

**비교 목적:** 두 시스템의 일치·불일치 및 변화 시점 차이 비교가 유력합니다. 실제 정답 기반 정확도 평가를 포함할 최종 범위는 외부 개발자와 확인해야 합니다.

**실험 방식:** 사전 계획한 자세·동작을 순서대로 수행하는 방식이 유력합니다. 자유 측정도 지원하며 실제 순서·반복 횟수는 미정입니다.

| 자세 후보 | 현재 의미 | 확인할 경계 |
|---|---|---|
| 누움 | 바로 누운 상태 | 자세 판정 기준 |
| 옆으로 누움 | 측면으로 누운 상태 | 좌·우 세분화 여부 |
| 걸터앉음 | 침대 가장자리에 앉음 | 침대 위 앉음과의 구분 |
| 일어남 | 침대에서 벗어나는 동작 또는 상태 | 이탈 시작·완료·유지의 구분 |

네 라벨은 외부 센서의 확정 사양이 아닙니다. 엎드림이나 좌·우 세분화를 초기 필수 라벨로 추가하지 않습니다.

## 미정 — 우선 확인

| 분야 | 확인할 사항 |
|---|---|
| 외부 연동 | 최종 검증 목적, 라벨·이벤트 정의, 원시/분류 출력, 전달·동기화 방식 |
| 촬영 환경 | 공간 크기, 침대 배치·출입 방향, 카메라 종류·위치·높이·화각 |
| 실행 방식 | 카메라 AI는 로컬 추론을 기본으로 함. 구체적인 개발 기술과 연동 방식은 미선정 |
| 모델·자료 | 관절 추정기, 자세 분류기, 데이터량·분할·평가 방법 |
| 판단 기준 | 이벤트 시작/완료, 판정 불가, 침대 영역 오류 감지 |
| 기록·성능 | 저장 형식·주기, 처리 속도·허용 지연·정확도 목표 |
| 실험 운영 | 반복 횟수, 관찰자, 동의·접근 권한·보관 기간 |

스마트폰을 **카메라 입력**으로 쓰는 Android/iPhone·USB/Wi-Fi 방식도 후보입니다. 아래의 웹 원격 조작 기능과 별개입니다.

- 스마트폰 웹 원격 제어, 모바일 AI 결과 표시/숨김, PC·모바일 역할 분담
- 녹화 영상 재생과 사후 정답 시점 수정 UI
- 추가 자세 세분화, 이불·신체 가림 대응, 실사용 환경 확대

## 기술 비교 제안 — 아직 미선정

MediaPipe Pose Landmarker·YOLO Pose·RTMPose를 같은 저장 영상에서 우선 비교하고 MoveNet을 경량 대안으로 유지합니다. 단순 자세 분류와 상태 전이 기준선을 먼저 만들고, 실험 결과에 따라 LSTM/TCN·그래프 모델 등을 검토합니다.

세부 후보는 [기술 후보 비교](TECHNOLOGY_CANDIDATES.md), [실험 계획](POSE_BENCHMARK_PLAN.md), 실행 순서는 [로드맵](../ROADMAP.md)에서 관리합니다. 문헌 조사만으로 모델을 채택하거나 성능을 확정하지 않습니다.

## 합의의 적용 범위

로컬 추론은 **실제 측정 경로의 기본 방향**이며 학습 수행 위치는 별도로 결정할 수 있습니다. 모델 예측이 외부 센서의 답이나 계획 목표를 보지 않는 독립성은 유지합니다. 후보 선택은 필요한 자세의 품질·안정성·실제 전체 지연을 검증한 뒤 결정합니다. 공통 비교 실험 설계는 완료했지만 성능 목표값과 모델은 아직 정하지 않았습니다.

## 앞으로 결정할 때

기술·요구사항을 확정하거나 바꿀 때는 결정일, 근거, 미해결 조건을 기록합니다. 기능의 구현 순서를 뒤로 옮기는 것과 기능 범위를 삭제하는 것은 구분합니다.
