# 결정 사항 및 미정 항목
기준선: v0.1 / 2026-10-24

## 합의된 개발 방향
- 카메라 AI와 외부 ToF·mmWave 결과의 독립 비교 검증
- 초기에는 통제된 침대 환경에 집중
- 선택적 원본 영상 녹화와 지속적인 실시간 분석·기록
- 단일·순차 측정, 자동·수동 진행 지원 방향
- 자세별 준비시간 설정 및 준비 완료 버튼 방식 모두 지원
- 계획 자세·AI 예측·검증 정답·외부 센서 결과 분리
- 침대 영역 자동 인식·재인식·수동 보정 지원 방향

위 항목은 구현 완료를 뜻하지 않습니다.

## 미정
카메라, PC 사양, 설치 위치, 스켈레톤 추정 기술, 프로그래밍 구조, 자세 분류 모델, 최종 자세·이벤트 정의, 수집량, 데이터 형식·기록 주기, 실시간 성능 목표, 센서 출력·동기화 방법, 평가 절차와 화면 배치.

## 추후 검토
스마트폰 웹 원격 제어, 모바일 AI 결과 표시·숨김, PC·모바일 역할 분담, 녹화 영상 재생 및 정답 수정, 분류 항목 추가, 이불 가림 대응, 침대 배치 변경 대응 고도화.

## 초기 검증 과제
누운 자세의 스켈레톤 품질, 사람과 침대 영역 관계, 화면 이탈과 인식 실패 구분, 예측 흔들림과 실제 변화 구분, 정답 신뢰성 및 시스템 간 시계 오차.
