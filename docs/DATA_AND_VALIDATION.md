# 데이터·정답·평가 기준

[프로젝트 홈](../README.md) · [시스템 구조](ARCHITECTURE.md) · [측정 절차](MEASUREMENT_PROTOCOL.md)

**기준일: 2026-10-26 · 저장 구조와 평가 설계 제안**

관절 추정 후보만을 동일 영상으로 비교하는 세부 절차·공통 COCO 17점 매핑안·실패 및 지연 기록은 [스켈레톤 기술 비교 실험 계획](POSE_BENCHMARK_PLAN.md)을 참조합니다. 계획은 작성했지만 실제 지표를 측정하지 않았습니다.

카메라와 외부 센서의 결과 비교를 준비합니다. 실제 정답이 확보되면 각 시스템의 정확도를 별도로 평가합니다. 저장 형식·주기·목표 수치·허용 오차는 미정입니다.

## 서로 다른 네 가지 라벨

| 출처 | 의미 | 평가에서의 역할 |
|---|---|---|
| 계획 목표 | 참가자가 하기로 한 자세 | 측정 제어·계획 대비 확인 |
| 카메라 AI | 영상에서 독립 추정한 결과 | 비교·평가 대상 |
| 외부 센서 | ToF·mmWave의 독립 결과 | 비교·평가 대상 |
| 실제 정답 | 관찰·영상 검토로 확인한 수행 내용 | 정확도 평가 기준 |

계획 목표와 예측을 실제 정답으로 자동 대체하지 않습니다. 정답 상태는 미확인·임시 기록·검증 완료·불확실 등을 구분할 수 있어야 합니다.

## 저장할 정보

| 그룹 | 기록 후보 |
|---|---|
| 실험·참가자 | 세션/영상 ID, 참가자 비식별 ID, 학습·검증·시험 분할 |
| 촬영 조건 | 장비, 시점·해상도·조명·가림, 침대 배치 |
| 시각 | 프레임 번호, 촬영 시각 또는 영상 PTS, 수신·추론 시작/종료·출력 시각 |
| 관절 원본 | 모델별 좌표·관절 정의·신뢰도/가시성·결측 마스크 |
| 관절 변환 | 공통 매핑, 신체 정규화 좌표, 침대 상대 위치, 보간·평활화 여부 |
| 검출·품질 | 인물 박스·추적 ID, 실패 유형, 연속 실패 구간 |
| 자세·이벤트 | 라벨, 판정 불가, 점유, 이탈·복귀 시작/완료, 자세 변화 |
| 침대 영역 | 좌표·버전, 자동/수동 설정 시각, 유효·불확실 상태 |
| 계획·정답 | 단계·목표·조작 시각, 실제 확인 라벨·이벤트 시각·확인 방법 |
| 센서 | 협의된 원시 값/분류 결과, 센서 측정 시각, 라벨·상태 |
| 녹화 | 영상 파일 식별자, 시작·종료, 세션 연결 |
| 실행 설정 | 코드·모델·가중치 버전/체크섬, 전처리·매핑·임계값 |

모든 처리 프레임과 이벤트를 별도 기록하는 방식을 시작점으로 검토합니다. 실제 주기와 보관 형식은 용량·성능을 확인해 정합니다. 촬영 시각이 없으면 사용한 대체 시각과 한계를 표시합니다.

## 평가 A · 두 시스템의 결과 비교

같은 실험·시간대·공통 라벨로 정렬해 다음을 집계합니다.

- 양쪽 결과가 모두 유효한 구간의 일치율과 라벨별 불일치
- 자세 변화·이탈·복귀 이벤트의 감지 시점 차이
- 양측 유효 구간 비율, 누락·판정 불가 구간과 시계 오차

**일치도는 정확도가 아닙니다.** 두 시스템이 같은 오답을 낼 수 있습니다. 최종 비교 범위와 시간 기준은 외부 개발자와 합의해야 합니다.

## 평가 B · 실제 정답 기준 성능

실제 수행을 별도로 확인한 구간에서 카메라와 센서를 각각 평가합니다. 계획 라벨만 있는 구간은 검증된 정답 평가에 포함하지 않습니다.

| 대상 | 제안 지표 | 함께 명시할 조건 |
|---|---|---|
| 관절 출력 안정성 | 누락률·연속 실패·정지 구간 흔들림 | 관절·자세·가림별 결과 |
| 관절 위치 정확도 | PCK 또는 MPJPE | 관절 정답, 차원·단위·정규화·임계값 |
| 자세 분류 | 클래스별 precision/recall/F1, macro-F1, 혼동행렬 | 라벨 정의·표본 수·분할 |
| 판정 불가 | 유효 비율·누락 비율·지속 시간 | 유효 구간 성능과 전체 적용 범위 |
| 이탈·복귀 | 이벤트 precision/recall, 오경보/시간, 누락 | 1:1 매칭·허용 시간창·중복 경보 처리 |
| 이벤트 시각 | 기준 시점 대비 시간차·분포 | 시작·완료·사전 경고, 부호·기준 시각 |
| 실시간 처리 | 처리량·프레임 드롭·전체 지연 p50/p95 | 장비·입력·전송·추론·출력 조건 |
| 운영 부담 | CPU/GPU·메모리 사용, 장시간 동작 | 설치 재현성·실제 Windows 장비 |

관절이 출력됐다는 사실과 좌표가 정확하다는 것은 다릅니다. 정답 인물 박스를 준 시험과 실제 사람 검출기부터 실행한 시험, 촬영 FPS와 추론 속도도 구분합니다.

## 분할과 시간 정렬

1. 참가자·세션 단위로 학습/검증/시험을 분리하는 계획을 우선 검토합니다.
2. 같은 녹화의 인접 프레임이나 겹치는 시간 창이 분할을 넘지 않도록 관리합니다.
3. 새 참가자 평가와 같은 참가자의 다른 세션 평가를 구분하고 분할 목록을 보관합니다.
4. 촬영·센서 측정 시각과 결과 도착·출력 시각을 구분합니다.
5. 영역 보정·미검출·불확실 구간의 포함/제외 기준과 비율을 보고합니다.

이벤트의 시작·완료 정의와 시간 정렬 오차를 정하기 전에는 감지 지연을 확정하지 않습니다.

## 보관과 재현

촬영 동의·접근 권한·보관 기간은 수집 전에 정합니다. 원본 영상·개인정보·학습/평가 데이터는 GitHub 저장소에 올리지 않습니다. 실행 설정, 촬영 조건, 라벨 수정 이력을 남겨 같은 실험을 다시 평가할 수 있게 합니다.
