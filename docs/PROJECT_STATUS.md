# 프로젝트 진행 현황

[프로젝트 홈](../README.md) · [로드맵](../ROADMAP.md) · [확정·잠정·보류 사항](DECISIONS.md)

**기준일: 2026-10-26 · 현재 단계: 기획·설계 및 문헌 검토 · 구현 전**

카메라로 침대 위 자세와 움직임을 독립 분석하고 외부 ToF·mmWave 결과와 비교하는 시스템을 준비하고 있습니다. 일치도와 이벤트 시점 비교가 유력한 주목적이며, 정답 기반 정확도 평가를 포함할 최종 범위는 외부 개발자와 확인해야 합니다.

## 완료한 작업

| 작업 | 현재 산출물 |
|---|---|
| 목적·범위 정리 | 통제된 침대 환경, 두 시스템의 독립성, 잠정 라벨 |
| 기능·운영 흐름 기획 | 실시간 분석, 단일·순차 측정, 준비 시간·완료 입력, 선택적 녹화 |
| 구조·평가 초안 | 분석 책임 분리, 시간 기록, 정답 관리, 비교 지표 |
| 논문 정리 | 침대 자세 24편·스켈레톤 기술 13편, 총 37편 |
| 원문 확인 | 33편의 공개 본문·저자판 관련 절·표 대조; 4편은 **본문 미확인·사실 판단 제외**(P11·P12·P19·P34); P35의 2022 최종 출판본은 **본문 미확인·해당 판본 판단 제외** |
| 기술 후보 정리 | 후보별 장단점·적용 방법·비교 기준 작성 |
| AI 작업 안내 | [공통 지침](../AGENTS.md)과 [작업 프롬프트](AI_TASK_PROMPT.md) 작성 |

**완료된 것은 기획과 자료 정리입니다.** 기능 구현이나 논문 성능의 재현 완료를 의미하지 않습니다. 논문의 수치 불일치·접근 제한은 해당 논문 항목에 표시했습니다. 미확인 본문 4편은 서지 검색 후보로만 남기고 기술 구현·성능 비교·설계의 사실 근거로 쓰지 않습니다. P35의 2022 ACM 최종 출판본도 미확인으로 분리합니다. P31·P35의 판본별·표별 주의사항을 문서에 기록했습니다.

## 다음 할 일

1. **외부 사양 확인:** 비교 목적, 최종 자세·이벤트 정의, 센서 출력, 시간 정렬 방식.
2. **촬영 조건 확인:** 침대 배치·출입 방향, 카메라 위치·화각, PC 자원. Windows 기준으로 논의 중이며 장비는 미정입니다.
3. **비교 자료 준비:** 잠정 자세, 자세 전환, 이탈·복귀가 담긴 동일 영상을 확보합니다.
4. **후보 실증:** MediaPipe Pose Landmarker·YOLO Pose·RTMPose를 우선 비교하는 안을 검토하고 MoveNet을 경량 대안으로 유지합니다. 관절 품질과 전체 지연을 함께 측정합니다.

외부 협의와 촬영 환경 조사는 병행할 수 있습니다. 모델 채택, 일정, 정확도·지연 목표는 실증과 협의 후 정합니다.
