# 참고 논문 상세 정리와 프로젝트 적용 계획

**기준일:** 2026-10-24 · **기획 버전:** v0.3 · **대상:** 침대 자세·움직임을 카메라 스켈레톤으로 분석하고 ToF·mmWave 결과와 독립 비교하는 프로젝트

지금까지 검토한 참고 논문 **25편**을 모았습니다. 각 항목에서 논문이 수행한 연구와 우리 프로젝트에 적용하려는 제안을 구분했습니다. 문헌 조사 결과이며, 이 저장소에서 모델을 구현하거나 논문 성능을 재현한 결과는 아닙니다.

## 읽는 기준

- **확인 범위:** 초록·서지 확인과 본문 방법·실험 확인을 구분합니다. 초록만 확인한 논문에서 참가자 분할·상세 장비·통계적 신뢰도를 임의로 채우지 않았습니다.
- **출처:** 학술지/학회, DOI, 저자 공개 원문을 우선 연결했습니다. SciSpace·Consensus는 검색·서지 확인을 보조했습니다. 프리프린트와 정식 게재 연도가 다른 경우 함께 표시했습니다.
- **입력 차이:** RGB, 근적외선/IR, 열영상(LWIR), 깊이, 압력은 서로 다른 입력입니다. MediaPipe 등에서 추정한 z 좌표는 깊이 센서 실측값과 같지 않습니다.
- **평가 차이:** 관절 위치 정확도, 자세 분류, 이탈 이벤트, 낙상 위험 예측은 별개입니다. 서로 다른 데이터와 분할에서 나온 정확도 숫자로 모델의 우열을 정하지 않습니다.
- **적용 제안:** 아래 우선순위와 활용점은 프로젝트 관점의 판단입니다. 논문의 결론이나 확정된 개발 사양으로 해석하지 않습니다.

### 프로젝트에서의 권장 읽기 순서

1. **실험 설계:** P15 → P01 → P12 → P11. 관절 데이터, 침대 위치, 시간 이벤트의 차이를 먼저 정리합니다.
2. **초기 구현 비교:** P05·P06 → P19 → P10·P20. 관절 추정과 단순 분류를 먼저 검증하고 시간 모델을 추가합니다.
3. **실제 환경 한계:** P21·P22·P14. 관절이 안 보이는 조건과 정답 수집 방법을 확인합니다.
4. **후속 확장:** P13·P04·P17, 이후 P07·P08·P09·P24. 가림·복잡한 시간 모델은 기준선과 비교합니다.
5. **별도 위험 예측:** P25. 낙상 위험 점수는 현재 이탈·복귀 비교 MVP와 다른 연구 과제로 둡니다.

### P01. Simultaneously-Collected Multimodal Lying Pose Dataset: Towards In-Bed Human Pose Monitoring under Adverse Vision Conditions

**저자·출처:** Shuangjun Liu 외. arXiv, 2020. 정식 게재 제목은 *Simultaneously-Collected Multimodal Lying Pose Dataset: Enabling In-Bed Human Pose Monitoring*, IEEE TPAMI 45(1), 1106–1118, 2023(온라인 2022).  
**링크:** [프리프린트](https://arxiv.org/abs/2008.08735) · [DOI: 10.1109/TPAMI.2022.3155712](https://doi.org/10.1109/TPAMI.2022.3155712) · [저자 데이터·코드 안내](https://github.com/ostadabbas/SLP-Dataset-and-Code)  
**확인 범위:** 논문 및 저자 데이터 설명의 입력·수집 조건·평가 목적.

- **문제와 방법:** 일반 인체 자세 데이터는 서 있는 사람이 많아 침대에 누운 자세와 이불 가림을 충분히 대표하지 못합니다. SLP는 동일 자세에서 RGB, 장파장 적외선(LWIR), 깊이, 압력 정보를 수집해 입력별 관절 추정 연구가 가능하도록 구성했습니다.
- **실험·자료:** 109명, 가림 없음·얇은 이불·두꺼운 이불 조건이 포함됩니다. 핵심 활용은 누운 자세의 관절 추정과 가림 조건 비교입니다.
- **장점:** 침대 도메인에 가까운 자료이므로 일반 자세 모델이 누움에서 실패하는 부분을 분석하고, 필요한 경우 전이 학습을 설계하는 데 유용합니다.
- **한계:** 정적 누운 자세 자료를 이탈·복귀 연속 영상 데이터로 취급하면 안 됩니다. 멀티모달 자료가 있다는 사실이 RGB만으로 가려진 관절을 정확히 찾을 수 있다는 뜻도 아닙니다.
- **프로젝트 활용 제안:** RGB 부분을 초기 관절 추정 점검에 활용하고, 가림 조건별 결과를 분리합니다. 실험 전 데이터 이용 조건, 참가자 분할, 관절 정의와 실제 촬영 시점의 차이를 확인해야 합니다.

### P02. Posture Monitoring for Health Care of Bedridden Elderly Patients Using 3D Human Skeleton Analysis via Machine Learning Approach

**저자·출처:** Jui-Chiu Chiang 외. *Applied Sciences*, 12(6), 3087, 2022.  
**링크:** [출판사 원문 / DOI: 10.3390/app12063087](https://www.mdpi.com/2076-3417/12/6/3087)  
**확인 범위:** 서지·초록 확인. 본문 세부 실험 조건은 추가 확인 필요.

- **문제와 방법:** 침대에 누운 사람의 자세를 RGB-D 카메라와 3D 스켈레톤으로 분류합니다. 이불로 몸이 가려지는 상황을 고려해 네 개의 3D 관절을 사용하는 접근입니다.
- **실험·결과:** 초록은 자세 인식 정확도 95% 이상을 보고하지만, 참가자 구성·분할·자세별 성능을 함께 확인하기 전에는 일반화 성능으로 받아들이기 어렵습니다. 논문은 향후 의료시설에서의 추가 시험도 언급합니다.
- **장점:** 전신 관절을 항상 얻을 수 있다는 가정 대신, 보이는 일부 관절을 활용한다는 설계가 참고할 만합니다.
- **한계:** 깊이 입력과 실제 3D 정보에 의존하므로 일반 RGB 카메라의 2D 관절 성능과 직접 비교할 수 없습니다. 이탈 이벤트의 빠른 감지를 검증한 연구로도 볼 수 없습니다.
- **프로젝트 활용 제안:** 상체 등 관찰 가능한 관절만으로 만든 특징 기준선을 검토합니다. 사용할 관절의 정확한 위치, 가림 조건, 참가자 분리 여부를 본문에서 확인한 뒤 재현 범위를 정합니다. 논문에 나온 자세 유지 경고 시간을 우리 시스템의 검증된 임상 임계값으로 채택하지 않습니다.

### P03. BedEye: A Bed Exit and Bedside Fall Warning System Based on Skeleton Recognition Technology for Elderly Patients

**저자·출처:** Liang-Bi Chen 외. *IEEE Access*, 13, 60403–60423, 2025.  
**링크:** [IEEE 원문](https://ieeexplore.ieee.org/document/10949079/) · [DOI: 10.1109/ACCESS.2025.3558004](https://doi.org/10.1109/ACCESS.2025.3558004)  
**확인 범위:** 서지·초록과 시스템 개요. 세부 성능표·시험 분할은 추가 확인 필요.

- **문제와 방법:** 스켈레톤 인식을 활용해 침대에서 일어나거나 침대 주변에서 위험한 움직임을 보이는 상황을 감시하는 시스템입니다. OpenPose 계열의 경량 스켈레톤 인식과 침대 주변 동작 판단을 연결합니다.
- **연구 의미:** 누운 자세의 단일 프레임 분류를 넘어, 몸을 일으키기·가장자리에 앉기·침대를 떠나는 흐름을 다룬다는 점이 현재 프로젝트와 가깝습니다.
- **장점:** 관절 모델만의 정확도가 아니라 실제 경고 시스템에서 필요한 상태 변화와 처리 구조를 살펴볼 수 있습니다.
- **한계:** 침대 이탈, 침대 옆 낙상, 낙상 위험은 같은 라벨이 아닙니다. 경고 시스템 구현이 실제 낙상 예방 효과를 입증한 것이라고 해석해서는 안 됩니다. 장비별 지연·가림·다인 환경 조건도 추가 검토해야 합니다.
- **프로젝트 활용 제안:** 자세 분류와 침대 상대 위치, 시간 이벤트를 분리하는 설계에 참고합니다. 논문의 상태 정의와 경고 조건을 먼저 대조하고 우리 센서의 '일어남' 라벨과 연결 가능한지 확인합니다.

### P04. RGB-Only in-Bed Pose Estimation Under Occlusion via Image Reconstruction

**저자·출처:** Sewon Kim, Hyebin Kim, Seohyun Lee, Taeyong Lee. *IEEE Access*, 14, 128244–128261, 2026.  
**링크:** [DOI: 10.1109/ACCESS.2026.3723433](https://doi.org/10.1109/ACCESS.2026.3723433) · [저자 소속기관의 초록·서지](https://pure.ewha.ac.kr/en/publications/rgb-only-in-bed-pose-estimation-under-occlusion-via-image-reconst/)  
**확인 범위:** 공식 기관 초록·서지. 본문 설정·추론 비용은 추가 확인 필요.

- **문제와 방법:** RGB 영상만으로 이불 등에 가려진 관절을 추정하기 위해 영상 복원 후 자세 추정을 수행합니다. MAE·AOT-GAN 복원 모델과 OpenPose·ViTPose·HRNet 조합을 비교하며 SLP로 복원 모델을 조정합니다.
- **실험·결과:** 초록은 복원 전처리의 관절 오차 개선과 별도 수집 데이터 평가를 보고합니다. 그러나 새로운 데이터에서 AOT-GAN 조합은 오히려 오차가 증가해, 복원 방식에 따라 일반화 결과가 달랐습니다.
- **장점:** 깊이·열영상 센서 없이 가림을 다루는 확장 방향을 제시합니다.
- **한계:** 복원 영상은 모델이 추정한 내용입니다. 보이지 않는 신체가 실제로 그 위치에 있다는 관측 증거나 정답으로 사용할 수 없습니다. 복원 단계가 추가되어 속도·오류 전파도 평가해야 합니다.
- **프로젝트 활용 제안:** 초기 MVP 이후 가림 문제가 주요 실패 원인으로 확인될 때 검토합니다. 원본 RGB 기준선, 복원 후 결과, 판정 불가 처리의 효과를 같은 시험 자료로 비교합니다.

### P05. BlazePose: On-device Real-time Body Pose tracking

**저자·출처:** Valentin Bazarevsky 외. arXiv:2006.10204, 2020, 프리프린트.  
**링크:** [논문](https://arxiv.org/abs/2006.10204)  
**확인 범위:** 원 논문의 모델 개요·대상 환경.

- **문제와 방법:** 모바일 기기에서 한 사람의 전신 자세를 빠르게 추정·추적하는 구조를 제안합니다. 검출과 추적을 연결하고 히트맵·좌표 회귀를 활용해 33개 신체 랜드마크를 다룹니다.
- **연구 의미:** MediaPipe 계열을 초기 구현 후보로 검토할 때 모델의 설계 목적과 출력 구조를 이해하는 기초 자료입니다.
- **장점:** 가벼운 실행 환경과 추적을 고려한 설계는 실시간 프로토타입의 출발점으로 적합한지 시험할 가치가 있습니다.
- **한계:** 일반 모바일 자세 인식 결과가 침대의 옆누움·이불·어두운 영상에서도 유지된다고 보장하지 않습니다. 원 논문과 현재 MediaPipe 배포 모델·API는 동일 버전으로 간주할 수 없습니다.
- **프로젝트 활용 제안:** 현재 사용할 패키지·가중치 버전을 고정하고 동일 침대 영상에서 관절 누락·흔들림·처리 시간을 측정합니다. 추정 깊이는 실측 깊이와 구분하고, 신뢰도와 가시성의 정의를 확인해 결측 처리에 사용합니다.

- **프로젝트 활용 제안:** 스켈레톤 방식의 장단점을 확인하는 보조 기준선으로 검토합니다. 이 연구만으로 스켈레톤 접근이 불필요하다고 결론내리지 않고, 동일 참가자 분할과 가림·이탈 조건에서 비교해야 합니다.

### P24. Deep State-Space Model for Noise Tolerant Skeleton-Based Action Recognition

**저자·출처:** Kazuki Kawamura, Takashi Matsubara, Kuniaki Uehara. *IEICE Transactions on Information and Systems*, E103.D(6), 1217–1225, 2020.  
**링크:** [DOI: 10.1587/transinf.2019MVP0012](https://doi.org/10.1587/transinf.2019MVP0012) · [J-STAGE](https://www.jstage.jst.go.jp/article/transinf/E103.D/6/E103.D_2019MVP0012/_article/-char/ja) · [저자 기관 PDF](https://da.lib.kobe-u.ac.jp/da/kernel/90007346/90007346.pdf)  
**확인 범위:** 본문의 DSSM·행동 분류 구조와 잡음/결측 평가 목적.

- **문제와 방법:** 잡음이 있거나 일부 관절이 누락된 스켈레톤의 시간적 잠재 상태를 학습하고, 얻은 표현을 행동 분류에 사용합니다. 분류 단계에는 양방향 LSTM이 포함됩니다.
- **연구 의미:** 한 프레임의 잘못된 좌표만으로 판단하지 않고 시간적 일관성을 활용하는 접근입니다. 평가는 일반 3D 스켈레톤 행동 데이터 중심입니다.
- **장점:** 침대 영상에서 반복될 수 있는 관절 잡음·결측 문제를 명시적으로 다룹니다.
- **한계:** 양방향 시간 모델은 미래 정보 사용 여부를 확인해야 하므로 전체 구간 평가를 실시간 저지연 성능과 동일시할 수 없습니다. 잡음 제거 결과는 가려진 신체의 실제 위치 정답이 아닙니다.
- **프로젝트 활용 제안:** 우선 결측 마스크와 단순 시간 필터 기준선을 만들고 추가 모델의 이득을 비교합니다. 오프라인 재분석과 실시간 경로를 구분해 지연·미래 프레임 사용을 기록합니다.

### P25. Fall-from-Bed Risk Prediction Using Physics-Based Bed Simulation

**저자·출처:** Jaeyong Kim 외. *Sensors*, 26(10), 2979, 2026.  
**링크:** [출판사 / DOI: 10.3390/s26102979](https://www.mdpi.com/1424-8220/26/10/2979) · 서지·초록 대조 [1](https://consensus.app/papers/fallfrombed-risk-prediction-using-physicsbased-bed-kim-kim/2033f2b2108c5c459e76d3cfcd7b0bf2/?utm_source=chatgpt)  
**확인 범위:** 초록·서지. Consensus 확인 당시 인용 수 0(2026-10-24, 품질 판단 기준 아님).

- **문제와 방법:** MuJoCo로 침대와 인체를 모델링하고 여러 초기 자세에서 3초 동안 제어 없는 움직임을 시뮬레이션합니다. 바닥 접촉과 낙상까지의 시간으로 위험 라벨을 만들고, 침대 좌표로 정규화한 13개 2D 관절을 MLP에 입력합니다. [1](https://consensus.app/papers/fallfrombed-risk-prediction-using-physicsbased-bed-kim-kim/2033f2b2108c5c459e76d3cfcd7b0bf2/?utm_source=chatgpt)
- **실험·결과:** 50,000개 초기 자세로 구성한 시뮬레이션 시험 집합에서 높은 예측 지표를 보고합니다. 이는 같은 시뮬레이터 동역학에서 정의된 위험 점수의 예측 결과입니다.
- **장점:** 신체 자세뿐 아니라 침대 경계와의 상대 위치가 중요한 정보를 담을 수 있다는 확장 아이디어를 제공합니다.
- **한계:** 실제 카메라 관절 오차·이불·자발적 움직임·현장 낙상에 대한 검증이 아닙니다. 정상 이탈, 낙상 발생 탐지, 낙상 위험도는 서로 다른 과제입니다.
- **프로젝트 활용 제안:** 침대 좌표 특징 설계의 참고 자료로 두되 현재 이탈·복귀 MVP에 위험 점수를 필수로 추가하지 않습니다. 적용하려면 실제 영상 기반 별도 검증이 필요하며 합성 위험 라벨을 실제 관측 정답으로 저장하지 않습니다.

### 최초 비교 실험 제안

1. 통제된 침대 영상에서 잠정 자세와 이탈·복귀, '몸을 일으켰지만 이탈하지 않음'을 함께 수집합니다.
2. 동일 원본 영상을 MediaPipe Pose·YOLO Pose·RTMPose에 입력하고 관절 매핑·신뢰도·실패·지연을 기록합니다. 후보 추가/제외는 실제 결과로 결정합니다.
3. 원본 좌표, 신체 정규화 좌표, 침대 상대 위치를 분리 저장합니다.
4. 규칙/SVM/RF/MLP 자세 기준선과 상태 전이 이벤트 기준선을 먼저 평가합니다.
5. 필요성이 확인되면 같은 분할로 LSTM/TCN을 추가하고, 그래프·히트맵 모델은 후속 비교로 둡니다.
6. 독립적으로 확인한 정답이 있는 구간의 성능과, 두 시스템 사이 일치도를 별도 보고합니다.

### 논문 수치를 비교하기 전에 확인할 항목

- 실제 입력이 RGB인지 IR·열영상·깊이인지, 측정 3D인지 모델 추정 3D인지.
- 시험에 새로운 참가자/세션이 들어가는지, 같은 영상의 인접 프레임이 학습과 시험에 섞이지 않았는지.
- 실제 검출기로 인물 박스를 얻었는지, 정답 박스를 제공했는지.
- 결측 프레임·어려운 구간을 제외했는지, 제외 비율과 판정 불가 비율이 보고됐는지.
- 실시간 평가인지 전체 영상의 미래 프레임을 사용한 평가인지.
- 자세 정확도인지 관절 위치 정확도인지, 이벤트 단위 지표인지.
- 데이터/코드/가중치를 실제로 사용할 수 있는지와 이용 조건.
