## 검증 상태

- 개발 환경에서 생성 영상·SDK 대역·오류/변조·기록 재계산·브라우저 동작을 검사했습니다.
- 이전 기능 커밋 [a5ee480](https://github.com/zntks1234/bed-pose-skeleton-ai/commit/a5ee4803eae61bb9cdc807c98e47ef60ced32266)의 [GitHub Actions](https://github.com/zntks1234/bed-pose-skeleton-ai/actions/runs/40798135896)는 Windows/Linux 테스트·빌드와 Linux 브라우저 검사를 통과했습니다.
- 2026-10-29 분리 구현은 Linux에서 전체 265개 개발 검사와 관련 후속 검사, 기존 브라우저 검사 2종·새 분리 브라우저 검사, 패키지 빌드를 확인했습니다. 생성 입력·SDK 대역 검사이며 실제 자세 정확도 검증은 아닙니다.
- 분리 커밋 c3128e3의 Actions는 Windows 통과·Linux 실패였습니다. 미리보기 치수 공개 전 FPS만 기다리던 테스트의 비동기 경쟁을 수정했습니다. 독립 영상 근거 연결·평가 도구의 최신 검사 결과는 해당 후속 커밋의 Actions를 기준으로 확인합니다.
- CLIP 라이브러리 설치/가져오기와 작은 무작위 가중치의 실제 Transformers CLIP 로딩·문장 캐시·이미지 추론을 확인했습니다. 연결·기록·브라우저는 명시적 대역으로 검사합니다. Hugging Face 다운로드는 프록시 403으로 차단돼 사전학습 가중치·첨부 마네킹·실제 사람의 CLIP 결과를 확인하지 못했습니다.
- 사용자 Windows PC의 실제 모델 실행과 일부 프레임 육안 검토 보고가 있습니다. 통제된 실제 장치 성능 시험과 구분합니다.
- 실제 사람의 관절 정확도·자세별 Precision/Recall/F1·보류율·전환 지연·다중 카메라 종단 지연은 아직 검증되지 않았습니다.
- 문헌 37편 중 P11·P12·P19·P34는 본문 미확인입니다. P35의 2022 ACM 최종판도 본문 미확인이고, 확인된 공개 판본의 근거만 사용합니다. [문헌 확인 범위](research/LITERATURE_REVIEW.md).

테스트 수는 변경되므로 이 문서에서 매번 누적하지 않습니다. 특정 실행의 결과는 해당 커밋의 Actions를 확인합니다. 기록 검사 통과를 자세 정확도나 실제 노출 프레임의 완전 수신으로 해석하지 않습니다.

## 다음 단계

CLIP 사전학습 자산을 준비하고 마네킹/별도 검토한 사람 자료에서 실제 결과를 평가합니다. CLIP 실행 제공자는 구현했으며, 자산 준비·CLIP 선택 시 0.8이고 미사용 시 0.7입니다. 같은 자료의 SigLIP 2 비교와 최종 모델 선정은 후속입니다. 실제 영상에서는 한 명·한 카메라·이불 없는 세 자세 유지/전환과 서 있음 등 범위 밖 동작을 별도 주석으로 평가합니다. 이후 시점·가림·주변 인물·두 카메라로 넓힙니다. 순서와 완료 기준은 [로드맵](../ROADMAP.md)에서 관리합니다.
